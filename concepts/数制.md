# 数字的数制表示

数字电路处理的是离散的数值表示，理解数制和编码是数字IC设计的第一步。所有的数据、地址、指令，在硬件层面最终都以二进制比特的形式存在和操作。

## 原理

### 二进制与进制转换

数字系统中，所有的信息最终都表示为二进制（Binary）——只有 {0, 1} 两个符号，分别对应电路中的低电平（GND）和高电平（VDD）。将十进制整数转换为二进制采用 "除 2 取余，逆序排列" 法；小数部分采用 "乘 2 取整，顺序排列" 法。反过来，二进制转十进制则按位权（Positional Weight）累加。十六进制（Hexadecimal）和八进制（Octal）是二进制的紧凑表示——每 4 位二进制对应 1 位 Hex，每 3 位对应 1 位 Octal——方便工程师阅读和调试。

### 有符号数的表示

数字系统中表示正负数有三种主要方式：
- **原码（Sign-Magnitude）**：最高位表示符号（0 正 1 负），其余位表示数值。简单直观但存在正零和负零两个零，加减法需要特殊处理。
- **反码（One's Complement）**：负数表示为对应正数按位取反，减法可转化为加法（需处理循环进位），同样有双零问题。
- **二进制补码（Two's Complement）**：现代数字系统的标准。负数的补码等于对应正数按位取反再加 1。补码的核心优势在于将减法统一为加法——同一套加法器硬件可以同时处理有符号和无符号运算，无需额外逻辑区分。

N 位补码的表示范围为 [-2^(N-1), 2^(N-1) - 1]，这个范围的不对称性（最小值比最大值的绝对值大 1）是补码的内在特性。

### 定点数与浮点数

**定点数（Fixed-Point）** 将小数点固定在特定位位置，所有运算本质上是整数运算。在 DSP（数字信号处理，Digital Signal Processing）和嵌入式场景中广泛使用，避免了浮点单元的硬件开销。定点数的动态范围和精度之间存在权衡——Q 格式（Q15、Q31 等）是常见的定点表示约定。

**浮点数（Floating-Point）** 遵循 IEEE 754 标准，由符号位（S）、指数（Exponent, E）和尾数（Mantissa/Significand, M）三部分组成：value = (-1)^S × (1.M) × 2^(E - bias)。浮点加法器需要经过对齐（Alignment）→ 加法 → 规格化（Normalization）→ 舍入（Rounding）四个步骤，硬件复杂度远高于定点加法器。IEEE 754 定义了多种精度：单精度（binary32）、双精度（binary64）、半精度（binary16）以及 bfloat16。

### BCD 与格雷码

**BCD（Binary-Coded Decimal）** 将每个十进制位独立编码为 4 位二进制，8421 BCD 是最常见的形式（每个十进制位用 4-bit 二进制表示，范围 0000-1001）。常见于金融计算（避免二进制-十进制转换舍入误差）和七段显示驱动。BCD 加法器在标准 4-bit 加法器基础上增加"和 > 9 时加 6 修正"的规则。

**格雷码（Gray Code）** 的相邻码字仅有一位变化，在跨时钟域 FIFO 指针编码和状态机状态编码中至关重要——能避免多比特同时翻转导致的采样错误。N 位二进制转格雷码：$G = B \oplus (B \gg 1)$；格雷码转二进制：$B_i = \bigoplus_{j=i}^{N-1} G_j$（逐位累积异或）。

### 定点数的量化效应与饱和算术

定点数是数字信号处理（DSP）实现的标准选择——FIR 滤波器、FFT 蝶形单元、图像处理管线均优先使用定点而非浮点，以节省面积和功耗。定点运算的精度由 **Q 格式** 定义：Qm.n 表示 m 位整数、n 位小数（总位宽 = m + n + 1，含符号位）。例如 Q0.15（即 Q15）用 16 位表示 $[-1, 1-2^{-15}]$ 范围。

定点运算引入的数值误差来自两方面：**量化误差（Quantization Error）**——将连续值或高精度值舍入到有限位宽，舍入噪声功率 $\sigma_e^2 = \Delta^2/12$（$\Delta$ 是量化步长）；**溢出错（Overflow Error）**——算术操作结果超出表示范围。DSP 工程师通过信号范围分析确定每一级运算的整数位宽，在溢出风险和精度损失之间折中。**饱和算术（Saturation Arithmetic）** 在溢出时输出最大值/最小值——而非回绕（Wrap-Around）——是图像处理（防止白点变黑点）和反馈控制系统的默认选择。

### Booth 编码与乘法器优化

二进制补码的一个精妙应用是 **Booth 编码（Booth Encoding）**——将有符号乘法中的部分积数量减半。标准乘法对 N 位乘数产生 N 个部分积；基-4 Booth 编码（Radix-4 Booth Encoding）将乘数每 3 位一组（重叠 1 位）编码为 $\{-2, -1, 0, +1, +2\}$ 五个值，部分积数量降至 $\lceil N/2 \rceil$。编码规则基于当前比特组 $(b_{i+1}, b_i, b_{i-1})$：

| $b_{i+1}b_i b_{i-1}$ | 操作 | 含义 |
|:---:|:---|:---|
| 000 / 111 | 0 | 全零/全一，不操作 |
| 001 / 010 | +1× | 乘数段开始处，加被乘数 |
| 011 | +2× | 乘数段中间，加 2×被乘数（左移 1 位） |
| 100 | -2× | 乘数段结束处，减 2×被乘数 |
| 101 / 110 | -1× | 乘数段结束处，减被乘数 |

基-4 Booth 编码是 Wallace Tree 乘法器和 Dadda Tree 乘法器的前端标准配置——现代处理器中 64-bit 乘法仅需 32 个部分积的压缩树。Booth 编码直接利用补码的性质（符号位可参与统一编码），这也是补码成为现代数字系统标准的深层原因之一。

### 舍入模式与数值稳定性

IEEE 754 定义了五种舍入模式——硬件设计中必须至少实现前四种：

- **就近舍入，偶数优先（Round to Nearest, Ties to Even, RNE）**：默认模式，统计上无偏——与中间值等距时选最低有效位为偶数的方向。这是最常用模式，避免了累积舍入偏差。
- **向零舍入（Round toward Zero, RZ）**：直接截断，正值偏向小、负值偏向大——C 语言的整数截断行为。
- **向正无穷舍入（Round toward $+\infty$）**：始终向上取整。
- **向负无穷舍入（Round toward $-\infty$）**：始终向下取整——即 Floor 函数。
- **就近舍入，远离零（Round to Nearest, Ties Away）**：与 RNE 类似但不强制偶数——用于十进制浮点。

舍入模式的选择影响数值算法的收敛性和精度：区间算术需要 RZ 和 $+\infty$/$-\infty$ 组合来界定真值范围；迭代求解器中 RNE 的统计无偏性对收敛至关重要。硬件实现中，舍入逻辑需要根据 Guard 位、Round 位和 Sticky 位（GRS）三比特来确定——Sticky 位是截断位之后所有位的逻辑或，指示是否存在非零残余。

### 汉明码与单比特纠错

数字系统的数据完整性通常依赖于检错/纠错码——最基本的是 **汉明码（Hamming Code）**，可纠正单比特错误并检测双比特错误（SEC-DED: Single Error Correction, Double Error Detection）。汉明码的核心思想是插入校验位使任意两个有效码字间的汉明距离（Hamming Distance，不同比特位置的数目）≥3。对于 $k$ 位数据，需要 $r$ 位校验码满足 $(k + r + 1) \leq 2^r$——例如 64-bit 数据需要 7 位校验码（$64 + 7 + 1 = 72 \leq 128$）。

在 SRAM 和寄存器文件中，SEC-DED 汉明码是抗软错误（Soft Error，由 α 粒子或中子轰击导致的单比特翻转）的标准保护手段——每 64 位加 8 位检验位（因为 72 位常用 8 位校验以便按字节对齐）。对于更高速的 DDR/Burst 接口，循环冗余校验（CRC）通过多项式除法的循环性质实现突发错误检测——CRC-32 是 AXI 和 PCIe 协议中的标准数据完整性保护。而在 NAND Flash 等非易失性存储中，更强的 BCH 码和 LDPC（低密度奇偶校验码）应对更高的原始误码率（RBER）。

## 关键要点

- **二进制是数字电路唯一操作对象**：二进制是数字电路的唯一操作对象，所有信息最终映射到比特流和寄存器
- **补码统一有符号与无符号运算**：补码将符号位直接参与运算，同一套加法器硬件统一处理 signed 和 unsigned——这是现代处理器 ALU 的设计基石
- **溢出与进位是不同的概念**：溢出（Overflow）和进位（Carry）是不同的概念：进位用于无符号数，有符号数通过最高两位的进位异或（$C_{N} \oplus C_{N-1}$）判溢出
- **符号扩展是 RTL bug 头号来源**：符号扩展（Sign Extension）保证不同位宽的有符号数正确操作：将符号位复制到高位——不遵守此规则是 RTL 中 signed/unsigned bug 的头号来源
- **算术右移与逻辑右移不可混淆**：算术右移（ASR）复制符号位（保持符号），逻辑右移（LSR）补零（视为无符号）——两者选择错误导致功能灾难
- **IEEE 754 特殊值必须正确处理**：IEEE 754 浮点数的特殊值：NaN（非数）、Infinity（无穷）、Denormalized（非规格化数）、带符号零——硬件必须正确处理每一个
- **定点数面积小功耗低延迟可预测**：定点数在 DSP 和图像处理中广泛使用：面积小、功耗低、延迟可预测——量化噪声 $\sigma_e^2 = \Delta^2/12$ 是系统级信噪比（SNR）计算的起点
- **格雷码是异步 FIFO 指针编码核心**：格雷码配合 2-FF 同步器可将 CDC 的 MTBF 控制在安全范围——异步 FIFO 指针编码的核心方案
- **饱和算术优于回绕算术**：饱和算术在图像处理和反馈控制中优于回绕算术：溢出时钳位到最大/最小值，避免了回绕造成的极端视觉伪影或控制回路振荡

- [[concepts/CMOS基础|CMOS 基础]] — 底层晶体管如何实现逻辑门来存储和运算这些比特，从单个反相器到 64-bit 加法器的每一级进位链
