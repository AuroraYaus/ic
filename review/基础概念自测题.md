# 基础概念自测题

数字IC 基础概念自测题——CMOS、功耗公式、亚稳态物理、温度效应与数制。适用方向：设计 / 验证 / 后端 / 架构（公共基础）。

#### 1. CMOS 反相器怎么工作？为什么静态功耗接近零？

**出处**：[[concepts/CMOS基础|CMOS基础]]

**要点**：（1）NMOS 导电电子传强 0、PMOS 导电空穴传强 1——互补结构在稳态下 PMOS 与 NMOS 恰好一个导通、一个截止；（2）任何输入组合下不存在 VDD 到 GND 的直流通路——对偶原理（PUN 与 PDN 对偶）保证；（3）静态功耗只有微小的漏电流；功耗发生在翻转瞬间（动态功耗）；（4）输入悬空或中间电平会导致双管导通——CMOS 输入端不允许悬空。

#### 2. 动态功耗公式 $P = \alpha C V^2 f$ 各项含义？哪个杠杆最有效？

**出处**：[[concepts/CMOS基础|CMOS基础]]、[[asic-flow/concepts/功耗分析|功耗分析]]

**要点**：（1）$\alpha$ 活动因子（每周期平均翻转概率）、$C$ 负载电容、$V$ 电源电压、$f$ 频率；（2）电压是平方项——VDD 降 10% 省约 19% 动态功耗，最有效的杠杆；（3）频率线性项——降频直接省电；电容来自工艺与扇出——减小负载、缩短走线；（4）时钟树 $\alpha = 1$ 翻转率最高——时钟门控收益最大（节省 20%-40%）。

#### 3. 亚稳态的物理机理？MTBF 公式的工程含义？

**出处**：[[concepts/亚稳态|亚稳态]]

**要点**：（1）采样窗口内输入变化使触发器输出进入亚稳态——中间电平振荡，解析时间常数 $\tau = C/g_m$ 决定恢复速度；（2）MTBF（平均无故障时间）与时钟频率、数据翻转率、解析时间常数、同步器级数相关——每多一级同步器 MTBF 指数级提升；（3）先进工艺 $\tau$ 从 5-10ps 降到 1-3ps（FinFET 高 $g_m$）——亚稳态反而恢复更快，但频率提升更快，同步器仍是标配；（4）亚稳态只能降概率不能消除——它是概率问题，不是确定性错误。

#### 4. 温度升高芯片变快还是变慢？温度反转是怎么回事？

**出处**：[[concepts/半导体基础|半导体基础]]

**要点**：（1）两种竞争机制：升温 → 晶格散射加剧 → 迁移率下降 → 变慢；升温 → $V_{th}$ 下降（约 -1~-2 mV/°C）→ 过驱动增大 → 变快；（2）高 VDD（过驱动大）时迁移率主导——越冷越快（传统直觉）；低 VDD 近阈值时 $V_{th}$ 主导——高温反而快，即温度反转（Temperature Inversion）；（3）工程后果：Signoff 必须高低温双角检查——高温不一定是"最慢角"；（4）超频拉高电压处于迁移率主导区——降温（液氮）提升 Fmax 的物理依据。

#### 5. PVT 变异是什么？工艺角（SS/FF/TT）怎么用于时序分析？

**出处**：[[concepts/半导体基础|半导体基础]]、[[asic-flow/concepts/静态时序分析|静态时序分析]]

**要点**：（1）Process（光刻/掺杂/氧化层偏差）、Voltage（IR 压降）、Temperature——器件延迟的三大变源；（2）工艺角是极端条件组合：SS（慢 NMOS 慢 PMOS）对应高温低压——Setup 最差角；FF 对应低温高压——Hold 最差角；（3）多工艺角多模式（MCMM）框架下每个场景独立 STA，违例必须全场景清零；（4）工艺角对功耗的影响比时序更大——FF 角漏电可达 SS 角 5-10 倍。

#### 6. 二进制、原码、反码、补码怎么转换？补码的加法溢出怎么判断？

**出处**：[[concepts/数制|数制]]

**要点**：（1）补码负数 = 反码 + 1——补码使减法变成加法（加负数的补码），硬件只需加法器；（2）$N$ 位补码范围 $-2^{N-1}$ 到 $2^{N-1}-1$——不对称（-128 存在、+128 不存在）；（3）溢出判断：同号相加变号——正 + 正 = 负 或 负 + 负 = 正即溢出；（4）符号扩展：算术右移补符号位、符号扩展保持数值不变——移位与扩展是硬件数据通路基本功。

#### 7. MOSFET 阈值电压由什么决定？体效应是什么？

**出处**：[[concepts/半导体基础|半导体基础]]

**要点**：（1）$V_{th}$ 由栅材料功函数、氧化层厚度与电荷、沟道掺杂、衬底偏置决定；（2）体效应：源衬电压增大使耗尽层展宽、$V_{th}$ 升高——串联堆叠管（NAND 上管）的 $V_{th}$ 高于单管；（3）$V_{th}$ 决定亚阈值漏电（$I_{sub} \propto e^{-V_{th}/nV_T}$）与速度的权衡——多 Vth 库（HVT/SVT/LVT）的物理基础；（4）FinFET/GAA 通过栅控增强压低亚阈值斜率——短沟道漏电控制的核心手段。
