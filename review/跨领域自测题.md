# 跨领域自测题

跨领域方法论自测题——时序收敛、低功耗、复位、反标、信号完整性与 CDC 体系。适用方向标签：设计 / 验证 / **后端** / 架构。

#### 1. 时序收敛（Timing Closure）的完整流程？为什么每阶段都要 STA？

**适用方向**：后端 · 设计　**出处**：[[cross-domain/concepts/时序收敛|时序收敛]]

**要点**：（1）综合 → 布局 → CTS → 布线的闭环迭代，每个阶段用更精确的延迟模型替代上一阶段的估算（WLM → 真实位置 → 真实时钟 → 真实 RC）；（2）每步精度的提升同时暴露新违例——收敛不是一步到位而是逐层逼近；（3）多工艺角多模式（MCMM）框架：SS 角查 Setup、FF 角查 Hold、功能/DFT/睡眠模式全覆盖；（4）收敛完成（全角 Slack ≥ 0 + DRC 清零）是 Tape-Out 前置条件——Slack 从深负到全正是收敛的直观标志。

#### 2. UPF 描述什么？电源域、隔离单元、保持寄存器怎么配合？

**适用方向**：后端 · 设计 · 验证　**出处**：[[cross-domain/concepts/低功耗设计|低功耗设计]]

**要点**：（1）UPF（Unified Power Format, IEEE 1801）描述电源意图：电源域划分、供电网络、电源开关、隔离/保持/电平转换策略；（2）电源门控：断电域用 Header/Footer 开关切断供电——消除亚阈值漏电；（3）隔离单元（Isolation Cell）：断电域输出钳位到已知值——防止 X 传播到常开域；（4）保持寄存器（Retention Register）：断电前保存状态、上电恢复——与隔离配合决定唤醒时间与浪涌电流（Inrush Current）。

#### 3. 时钟门控、电源门控、DVFS 分别治什么功耗？怎么选择？

**适用方向**：设计 · 后端　**出处**：[[cross-domain/concepts/低功耗设计|低功耗设计]]

**要点**：（1）时钟门控：阻止空闲寄存器时钟翻转——治动态功耗（20%-40% 节省），零唤醒代价，第一优先；（2）电源门控：待机时切断模块供电——治漏电（降到近零），代价是唤醒延迟 + 浪涌电流 + 隔离/保持单元面积；（3）DVFS：按负载调电压频率——$P \propto V^2 f$ 双杠杆，需时钟频率可调 + 电压调节器 + 软件调度；（4）选择逻辑：看活动率分布——持续高活动用 DVFS、间歇空闲用门控、长待机用电源门控，组合使用。

#### 4. 异步复位同步释放电路怎么设计？复位树要注意什么？

**适用方向**：设计 · 后端 · 验证　**出处**：[[cross-domain/concepts/复位策略|复位策略]]

**要点**：（1）异步复位同步释放：复位信号异步有效（立即复位、不依赖时钟）→ 经两级触发器同步后释放（消除释放沿与时钟沿竞争）；（2）复位同步器输出驱动全局复位树——每个时钟域各一个，避免跨域复位路径；（3）复位释放要与时钟对齐——同步器输出在时钟域内无亚稳态风险；（4）复位策略验证要点：上电序列、复位释放后的首拍状态、复位期间输出状态（隔离或已知值）、复位与时钟门控/电源门控的配合。

#### 5. 反标（Back-Annotation）是什么？SPEF/SDF/VCD 各反标给谁？

**适用方向**：后端 · 验证　**出处**：[[cross-domain/concepts/反标|反标]]

**要点**：（1）反标是下游物理数据回填到上游分析工具——每切换一次精度上一个台阶；（2）SPEF（寄生参数）→ 反标给 STA 与功耗引擎——真实互连 RC 替换线负载模型；（3）SDF（延迟）→ 反标给门级仿真器——零延迟切换为真实门级时序，毛刺可见；（4）VCD/SAIF/FSDB（活动）→ 反标给功耗引擎——默认翻转率切换为真实活动；反标缺失时工具静默回退默认值——精度静默退化是最隐蔽的坑。

#### 6. 功耗仿真中的 SPEF 是什么？它和网表是什么关系？

**适用方向**：后端 · 设计　**出处**：[[asic-flow/concepts/功耗分析|功耗分析]]、[[cross-domain/concepts/反标|反标]]

**要点**：（1）SPEF（IEEE 1481）是寄生提取工具输出的文本文件，逐线网描述互连的分布式 RC（总电容/耦合电容/电阻）——功耗仿真中"真实电容值"的来源；（2）网表定义"谁和谁相连"的逻辑拓扑，SPEF 描述这些连接的电气属性（电阻多大、电容多大）——同一网表配不同布局版本提取的不同 SPEF，功能相同、电气行为与功耗不同；（3）名称匹配是两者一一对应的唯一桥梁：SPEF 按网表线网名组织、层次路径必须一致，对不上的线网静默回退 WLM（误差 15%-30%）；（4）SPEF 经两条路径影响功耗：开关功耗的 $C_L$ = 网表单元负载 + SPEF 互连电容（先进工艺长线可过半）；负载/slew 真实化后 NLPM 查表才准——布局后带 SPEF 误差收敛到 5% 以内。

#### 7. CDC 有哪些典型场景？验证方法是什么？

**适用方向**：设计 · 验证　**出处**：[[cross-domain/concepts/跨时钟域设计|跨时钟域设计]]、[[rtl-design/concepts/跨时钟域设计|跨时钟域设计]]

**要点**：（1）典型场景：单比特控制信号（两级同步器）、多比特数据总线（格雷码 + 同步器/握手/异步 FIFO）、快到慢与慢到快（脉冲展宽问题）；（2）CDC 结构检查靠静态 CDC 工具（Spyglass CDC/Meridian）——识别未同步路径、重收敛（Reconvergence）、亚稳态扇出；（3）CDC 功能验证：随机相位对齐仿真、协议检查器——同步器只能保证概率，协议层必须保证数据正确；（4）常见 bug：多比特打拍同步（错误）、格雷码比较前未同步、脉冲在慢域丢失——每类都有标准对策。

#### 8. IR 压降怎么影响时序？怎么修？

**适用方向**：后端　**出处**：[[cross-domain/concepts/时序收敛|时序收敛]]、[[asic-flow/concepts/功耗分析|功耗分析]]

**要点**：（1）IR 压降：电流流过 PDN 电阻使单元实际电压低于 VDD——静态 IR（平均电流）与动态 IR（di/dt 尖峰，可达平均 5-10 倍）；（2）VDD 降低 → 门延迟增大 → 局部 Setup 违例——Signoff 最隐蔽的时序问题来源；（3）修复：电源网格加密、去耦电容（DECAP，占面积 5%-15%）、高功耗区域布局约束（热点分散）；（4）动态 IR 与 STA 时序窗口结合分析——寄存器同步翻转簇是尖峰来源。

#### 9. UPF 低功耗仿真验证什么？X 传播怎么处理？

**适用方向**：验证 · 后端　**出处**：[[asic-flow/concepts/功耗分析|功耗分析]]、[[cross-domain/concepts/低功耗设计|低功耗设计]]

**要点**：（1）低功耗仿真验证电源意图的实现正确性：关电/上电序列、隔离钳位、保持寄存器保存/恢复、电平转换器行为；（2）断电域输出未隔离 → X 大范围传播 → 仿真失败或虚假比对错误——隔离单元是 X 的防火墙；（3）验证平台要按 UPF 建模隔离行为，与功能验证的电源序列测试协同；（4）注意区分：UPF 仿真验证"电源行为对不对"，功耗分析算"功耗多少"——两个不同目标。

#### 10. 高速信号的过冲（Overshoot）是怎么产生的？端接匹配怎么抑制？

**适用方向**：后端 · 架构　**出处**：[[cross-domain/concepts/信号完整性|信号完整性]]、[[architecture/concepts/DDR接口与PHY训练|DDR接口与PHY训练]]

**要点**：（1）过冲/下冲/振铃同源于阻抗不连续的反射：反射系数 $\Gamma = \frac{Z_L - Z_0}{Z_L + Z_0}$——接收端高阻近似开路（$\Gamma \approx +1$）正反射叠加出过冲，驱动端输出阻抗 10-35 Ω 低于 $Z_0$ 使反射在两个失配端间反弹成振铃；（2）判据是上升时间不是时钟频率：$t_r \le 2 t_{pd}$ 时传输线效应显著，有效带宽 $f_{BW} \approx 0.35/t_r$；（3）危害：超过 AMR 损伤器件、噪声裕量损失、振铃落入不确定区产生假时钟、眼图闭合 BER 上升、EMI；（4）端接三方案：源端串联（$Z_{out} + R_S = Z_0$，零直流功耗，适合单向点对点）、终端并联/戴维南（$R_{T1} \parallel R_{T2} = Z_0$、$V_{TT} = V_{DD}/2$，彻底消反射但持续直流功耗）、ODT 片上终结（可编程档位 + ZQ 校准对抗 PVT 漂移）。
