# 数字IC复习自测题库

数字IC 全栈复习自测入口。**题目全部来自库内已有内容**——每题附答案要点提纲与出处链接，要点不在题集内展开（细节回出处文件）；库外高频考点登记在下方"待补考点清单"，逐项补齐后才会出题。

## 使用方法

1. **适用方向标签**：每题标注适用适用方向（设计 / 验证 / 后端 / 架构），按你的目标方向筛选阅读
2. **自测流程**：遮住"要点"自行作答 → 对照要点查缺 → 有缺口回到出处文件精读
3. **选题依据**：各章题目按对应领域 MOC 的"高频查询排名表"（queries 计数）排热度——查询次数高 = 易忘 = 易考
