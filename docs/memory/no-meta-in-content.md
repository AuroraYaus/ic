# 元指令不入正文

**用户对写作方式的要求是后台操作指令，严禁以任何标签形式泄露到知识库文档正文中。**

## 禁止的元标签

| 禁止出现 | 原因 |
|:---|:---|
| "润色后的问题" | 这是写作过程，不是知识内容 |
| "用户问" / "根据要求" | 暴露了对话来源，破坏了文档的独立参考价值 |
| "按要求回答" / "本节回答" | 文档不应知道自己是被"写"出来的 |
| `> **润色后**：` 引用块 | 章节标题就是议题，不需要声明"这是润色后的" |

## 正确做法

- 润色后的标题作为章节标题（`###`）自然融入
- 需要引出问题语境时，用知识本身的语言，不用元写作语言
- 读者打开文档看到的是**知识**，不知道也不关心这段内容是怎么被写出来的

**Why:** SVA断言.md 和 SystemVerilog.md 中曾出现"润色后的问题"标签——用户指出这是把写作要求泄露到了正文中。知识库是独立的知识参考，不是对话日志。

**How to apply:** 每次写入知识库文件前自查——含"润色"、"用户"、"要求"、"回答"等元写作词汇的行全部删除。
