用户曾要求"把网页里的截图去掉水印存到本地、在文章中引用"——去水印部分予以拒绝：去水印 = 移除作者署名痕迹，公开仓库（Gitee + GitHub）中构成侵权风险。用户随后改为"不去水印"——该形式可接受。

**Why:** 去水印是主动抹掉权利标识，性质恶劣；保留水印 + 正文标注出处（作者、文章标题、原文 URL）属于《著作权法》第 24 条"为说明某一问题适当引用已发表作品"的教育性合理使用，教学知识库中单图引用是普遍接受的实践。

**How to apply:** （1）**禁止**：下载第三方图片后去除水印/裁掉署名再入库；（2）**允许**：带水印原图 + 出处标注入库——出处写在前端或图注（作者 + 标题 + URL）；（3）**技术分工**：网页有反爬时（如知乎返回挑战页）由用户自行"图片另存为"获取原图，不用截图（截图叠水印且分辨率低）；（4）文件名规范（如 `setup-hold-ref-zhihu.png`），与手绘资产区分；（5）版式参考仍然首选自绘——自绘图无任何版权负担。

**本案记录（2026-10-12）**：setup/hold 配图先手绘 SVG 两轮（用户嫌丑、嫌 Wavedrom 多周期），最终用户选择删除手绘 SVG，采用两张带水印知乎原图 + 出处链接入库——用户偏好原图引用胜过自绘，后续遇到类似配图需求先问"原图引用还是自绘"。
