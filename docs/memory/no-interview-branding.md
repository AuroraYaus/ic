用户中途纠正："不要把面试这种很直接的文字写入库中，别人看到了不好"。当时正在建 interview/ 面试题集（文件名、章节标题、岗位标签、使用方法全是面试语境），全部返工改名——目录 review/、文件"XX自测题"、"岗位"改"适用方向"、"手撕"改"编程"，PLAN.md 同步重写。

**Why:** 该仓库双推到 GitHub/Gitee、公开可见。求职语境是使用场景元信息而非知识本身——它泄露个人求职状态、把知识库变成求职材料，专业观感受损；且与"元指令不入正文"同源：读者应只看到知识，不看到知识的使用动机。

**How to apply:** 题库/练习/速查类内容一律用"复习自测/自测题/适用方向"表述；新写作动笔前检查是否含使用场景泄露词（面试/求职/备考/刷题/上岸等）；批量替换后必须全目录残留扫描闭环（本次靠 python 复扫确认 0 残留）。关联 [[no-meta-in-content]]、[[qa-enumeration-expansion]]。
