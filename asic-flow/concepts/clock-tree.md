# 时钟树综合（Clock Tree Synthesis）

时钟树综合（Clock Tree Synthesis, CTS）是物理设计中构建时钟分配网络的关键阶段。时钟信号的"心跳"特性决定了 CTS 的独特性：每个时钟周期内，所有受时钟驱动的时序单元必须在一个可控的时间分布窗口内接收到时钟沿。CTS 的目的不是传播"最快的"时钟，而是传播"最平衡的"时钟。

## 原理

### CTS 优化目标体系

CTS 有四个按优先级排列的优化目标。第一优先级是**最小化时钟偏斜（Skew）**：同一下降沿/上升沿到达任意两个触发器时钟输入端的时间差，包括全局偏斜（片上任意两点）和局部偏斜（相邻寄存器）。正的局部偏斜会侵蚀建立时间预算（捕获时钟晚于发射时钟），负偏斜会侵蚀保持时间预算——偏斜控制失败直接导致芯片功能错误。

第二优先级是**控制插入延迟/传播延迟（Latency）**：时钟信号从 PLL 输出端到寄存器时钟输入端的绝对传播时间。过大的时钟延迟增加 I/O 接口的时序预算压力，延长扫描测试移位时间。第三优先级是**满足信号完整性约束**：上升/下降过渡时间（Slew/Transition）必须在工艺库限制内，过缓的时钟沿会扩大寄存器的有效建立-保持窗口并增加短路功耗。第四优先级是**最小化时钟树功耗**——时钟信号每个周期翻转（活动因子 $\alpha = 1$），时钟树功耗通常占芯片动态功耗的 30%-40%，远超其面积占比。

### 时钟树拓扑结构

不同性能需求对应不同的拓扑选择。**H 树（H-Tree）**：以递归 H 形几何结构布线，从中心到各叶节点的曼哈顿距离完全相等——理论零偏斜，但布线资源消耗大、仅适合对称布局，在 SoC 中多用于顶层全局分配。**X 树**为其不规则版图的变体。**CTS 平衡树**由 EDA 工具通过动态规划/DME（Deferred Merge Embedding）算法自动插入缓冲器和反相器实现延迟平衡，是 ASIC 主流方案。

在高性能场景中，**时钟网格（Clock Mesh）**提供亚 5ps 级超低偏斜：顶层密集金属网格由多个缓冲器同时驱动，寄存器从最近网格交叉点取时钟，代价是极大的功耗和金属资源。**时钟脊柱（Clock Spine）**为网格和树之间的折中——单根或多根宽金属线脊柱配合水平分支，偏斜性能和功耗均居中。

### 反相器对与有用偏斜

时钟树上倾向使用反相器对（Inverter Pair）而非缓冲器：反相器面积更小、功耗更低、上升/下降沿更对称，但必须确保每对反相器保持偶数级反相以保证相位对齐。**有用偏斜（Useful Skew）**主动利用偏斜优化——延迟捕获时钟增大建立时间余量（正偏斜），延迟发射时钟增大保持时间余量（负偏斜），是"以偏斜换时序"的关键技术。Useful Skew 的实施需要 CTS 与 STA 引擎紧密协作，迭代分析延迟调整的连锁效应。

### CCD 与多电压挑战

并发时钟与数据优化（Concurrent Clock and Data, CCD）将时钟延迟和数据路径延迟放在同一框架下协同优化，大幅减少传统"CTS -> STA -> ECO"迭代。多电压设计中，时钟路径穿越不同电压域时需要插入电平转换器（Level Shifter）。多模多角约束下 CTS 必须同时收敛功能模式、扫描移位模式、BIST 模式等多种场景。扫描移位模式下时钟树负载远大于功能模式，是全芯片 CTS 约束中最难满足的条件之一。

## 关键要点

- CTS 优化目标有明确优先级：偏斜（Skew）> 延迟（Latency）> 信号完整性（Slew）> 功耗
- 时钟树功耗占芯片动态功耗的 30%-40%，因为时钟活动因子 $\alpha = 1$，远高于数据信号的典型 $\alpha = 0.1$`-`$0.2$
- 反相器对优于缓冲器（面积小、功耗低、沿对称），但必须保证偶数级以保持相位一致
- 有用偏斜（Useful Skew）是"以偏斜换时序"的核心技术——延迟捕获时钟修复 Setup，延迟发射时钟修复 Hold
- H 树提供理论零偏斜但布线成本高；平衡树是 ASIC 主流；网格提供 <5ps 偏斜但功耗和资源代价大
- CCD 统一优化时钟和数据延迟，大幅减少时序迭代，是高频设计的关键使能技术
- 多电压设计中时钟路径上的电平转换器是必须的，CTS 必须考虑多电压域的传播延迟变化
- 扫描移位模式下时钟树负载远大于功能模式，多模多角 CTS 约束是物理设计中最复杂的部分

## 与其他概念的关系

- [[asic-flow/concepts/static-timing-analysis|静态时序分析（STA）]] — CTS 输出真实时钟延迟，供 STA 精确验证建立/保持时间，替代理想时钟假设
- [[asic-flow/concepts/place-and-route|布局布线（P&R）]] — CTS 位于全局布局和详细布线之间，CTS 后的时钟走线是详细布线的关键部分
- [[asic-flow/concepts/power-analysis|功耗分析（Power Analysis）]] — 时钟门控是降低时钟树功耗的核心手段，时钟树功耗分析是签核的必要环节
- [[asic-flow/concepts/synthesis|逻辑综合（Synthesis）]] — 综合阶段假定时钟理想抵达，CTS 后的真实时钟延迟可能导致时序重新收敛
- [[cross-domain/concepts/timing-closure|时序收敛（Timing Closure）]] — 有用偏斜和 CCD 是跨越 CTS 与 STA 边界实现最终时序闭合的关键技术
