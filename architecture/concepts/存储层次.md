# 存储层次

存储层次是计算机体系结构中最基本的设计原则之一，其核心思想是利用程序访问的局部性原理，通过多级不同容量、不同速度的存储设备构建金字塔结构——从容量小、速度快、离处理器最近的寄存器堆到容量大、速度慢、离处理器最远的磁盘/SSD。每一级存储作为上一级的缓存，以接近上一级的速度提供接近下一级的容量，将平均访问时间（Average Memory Access Time, AMAT）最小化。

## 半导体存储器技术

半导体存储器是数字系统存储层次中各物理级的具体实现技术。根据数据保持方式、访问特性和制造工艺，半导体存储器分为易失性存储器（Volatile Memory，断电数据丢失）和非易失性存储器（Non-Volatile Memory, NVM，断电数据保持）两大类。

### SRAM 与 DRAM

**静态随机存取存储器（Static Random Access Memory, SRAM）**和**动态随机存取存储器（Dynamic Random Access Memory, DRAM）**是最主要的两种易失性存储器技术，两者在存储单元结构、访问速度、密度和成本上存在根本差异。

**SRAM 存储单元**：经典 6T SRAM 单元由 6 个晶体管构成——4 个晶体管组成交叉耦合反相器对（存储节点），2 个晶体管作为访问管（Word Line 控制）。交叉耦合反相器形成双稳态（Bistable）——两个稳定状态分别存储 0 和 1，只要有电源供电，数据就无限期保持（无需刷新）。SRAM 在空闲时仅消耗漏电功耗。由于 6T 结构面积大（每比特 6 个晶体管 + 阱区面积），SRAM 密度远低于 DRAM——典型 SRAM 比特单元面积约为 DRAM 的 10-20 倍。但 SRAM 访问速度快（1-10ns），数据保持不需要刷新操作，时序控制简单（单端口读写操作）。

**DRAM 存储单元**：经典 1T1C DRAM 单元由一个访问晶体管和一个存储电容组成——数据以电荷形式存储在电容上（电容有电荷=1，无电荷=0）。1T1C 结构比 6T SRAM 面积小得多，密度极高。但存储电容的电荷会通过 PN 结漏电和晶体管亚阈值漏电逐渐流失——数据保持时间典型为 64ms（在 85°C 工作温度下）。因此 DRAM 需要**刷新（Refresh）**操作——在数据丢失之前周期性读出并重新写回每个存储行。刷新操作的周期（tREF）通常为 64ms，期间所有行必须被刷新一次。刷新操作消耗带宽和功耗——DDR4/DDR5 中刷新开销约占 3-5% 的总带宽。

**SRAM 与 DRAM 的应用场景**：SRAM 用于需要极低延迟和确定性的场景——处理器 L1/L2/L3 缓存、寄存器堆、TLB、网络交换芯片的包缓冲器。DRAM 用于需要高密度、大容量的场景——计算机主存、图形帧缓冲器（GDDR）、手机运行内存（LPDDR）、服务器大容量内存（DDR5 DIMM）。两者需要刷新操作是核心的物理区别——SRAM 静态保持（有电即保持）、DRAM 动态泄漏（需要周期性刷新），这源自存储原理的物理差异（双稳态触发器 vs 电容电荷存储）。

### ROM 及其演进家族

**只读存储器（Read-Only Memory, ROM）**在制造时或编程后数据固定，正常操作只能读取、不能写入。ROM 家族按编程方式演进：

- **掩模 ROM（Mask ROM）**：数据在芯片制造的掩模阶段写入（通过金属层定制），制造成本高（需要定制掩模），单位成本最低（大批量），但数据一次性固定、不可更改。用于固化的启动代码和嵌入式系统固件（但现在已大量被 Flash 替代）。
- **PROM（Programmable ROM）**：出厂时所有位为 1（或 0），用户通过专用编程器一次性熔断保险丝（或反熔丝）编程。OTP（One-Time Programmable）特性——编程后不可擦除。
- **EPROM（Erasable PROM）**：通过紫外线擦除整个芯片内容（石英窗口 20-30 分钟紫外线照射），电信号重新编程。可多次擦除编程，但需要专用 UV 擦除器且擦除时间长。
- **EEPROM（Electrically Erasable PROM）**：电子擦除和编程——不需要紫外线照射，可单字节或单页擦除改写。擦写次数有限（典型 10^5 次），写入速度比读取慢得多（毫秒级 vs 纳秒级），但为系统内可编程固件提供了灵活性。

### 闪存（Flash Memory）

**闪存（Flash Memory）**是 EEPROM 的演进技术，通过浮栅晶体管（Floating Gate Transistor，FGT）存储电荷实现非易失存储。浮栅被氧化层隔离——电子通过热载流子注入或 Fowler-Nordheim 隧穿写入/擦除浮栅，改变晶体管的阈值电压（Vth），进而区分 0 和 1。

Flash 分为两大架构：

- **NOR Flash**：存储单元并联（类似 NOR 门的并行连接），支持按字节随机读取（XIP——eXecute In Place，代码可直接在 NOR Flash 中执行），读取延迟类似 SRAM（约 70-100ns），但写入和擦除速度极慢（秒级擦除整个块）。NOR Flash 典型的应用是存储启动代码（Bootloader）、固件和嵌入式系统的代码存储——因为随机读取快但写入慢且密度低（单位比特成本高）。

- **NAND Flash**：存储单元串联（类似 NAND 门的串联连接），按页读写、按块擦除。NAND 密度远高于 NOR（每个比特单元面积约 NOR 的 1/2-1/3），成本低，顺序读写速度快，但随机读取延迟大（无 XIP 能力）。NAND Flash 是 SSD、USB 闪存盘、SD 卡、手机存储的主流技术。现代 3D NAND 将存储单元垂直堆叠（高达 200+ 层），进一步提升密度。

**Flash 与 ROM 的根本区别**：Flash 可被反复擦写（10^3-10^5 次擦除周期），而 Mask ROM 完全不可改、PROM 一次性编程。Flash 的擦除以块（Block）为单位（NAND Flash 典型块大小 4-16MB），写入以页（Page）为单位（典型页大小 16KB），读取可按页或子页——这种块/页不对称性是 Flash 不同于 RAM（按字节读写的对称性）的核心特征，也是 Flash 转换层（Flash Translation Layer, FTL）需要处理的核心复杂性（写入放大、垃圾回收、磨损均衡）。


## 原理

### 局部性原理

局部性原理（Principle of Locality）是存储层次得以成立的理论基础，分为时间局部性（Temporal Locality）和空间局部性（Spatial Locality）。时间局部性指一个内存地址被访问后，短期内很可能再次被访问——这是缓存工作的基础，最近访问的数据和指令保留在较快存储中。空间局部性指一个内存地址被访问后，其邻近地址很可能很快被访问——这是缓存行（Cache Line / Block）粒度取数的依据，每次缓存缺失时从下一级取出整整一个块（通常 64 字节），提前将可能需要的邻近数据带上。指令流天然具有强空间局部性（顺序执行），数据流中的数组遍历、结构体字段访问也遵循空间局部性。Denning 的工作集模型（Working Set Model）将程序访存行为形式化为时间窗口内的地址集合——只要工作集能放入缓存就不会发生容量缺失。

### 缓存组织方式

缓存的组织方式由三个参数定义：缓存总容量（C）、块大小（B）、组相联度（Associativity, N）。三种组织方式：直接映射（Direct-Mapped, N=1）——每个内存地址仅能放入缓存中的唯一定位，硬件最简单但冲突缺失（Conflict Miss）率最高；全相联（Fully-Associative）——任何地址可放入任何位置，缺失率最低但硬件最复杂，需 CAM 搜索或全并行 Tag 比较，仅适用于小容量结构（如 TLB）；组相联（Set-Associative, N-way）——每个地址可放入 N 路中的任一路，由 Index 选组后组内选路，是实际处理器的主流方案。L1 数据缓存通常 4-8 路，L2 为 8-16 路，L3 为 16-20 路。缓存索引位宽 = log2(C / B / N)，Tag 位宽 = 物理地址宽度 - Index 位宽 - 页内偏移位宽。

### 替换策略

当缓存缺失且目标组所有路都被占用时，替换策略（Replacement Policy）决定淘汰哪个缓存行。LRU（Least Recently Used）跟踪每路的访问时间戳，淘汰最久未访行——理论最优但硬件开销 O(N log N) 位。伪 LRU（Pseudo-LRU / Tree-PLRU）用二叉树近似：每次访问沿路径标记，替换时沿未标记方向找——N 路仅需 N-1 位，精度下降约 5-10%。RRIP（Re-Reference Interval Prediction）是现代处理器的实际主流策略：每行分配一个 RRPV 值，新插入时根据策略预设（Near-immediate 或 Long），每次命中清零，替换选 RRPV 最高者。RRIP 对扫描模式抵抗力显著优于 LRU——LRU 遇扫描流会将整个组刷成新数据而淘汰所有有用行；RRIP 给扫描数据分配高 RRPV，一旦扫描结束这些行立刻成为候选淘汰对象。SHiP（Signature-based Hit Prediction）通过访存 PC 的签名历史预测插入策略。

### 写策略

写策略决定处理器写操作如何传播到缓存和下级存储。写直达（Write-Through）——Store 同时写缓存和下级存储，保证缓存与下级一致，实现简单但产生大量写流量。写回（Write-Back）——Store 仅写缓存并标记为脏，被替换时才写回下级，显著减少写流量。写分配（Write-Allocate）——Store 缺失时先将缺失行读入缓存再写入，与写回配对；非写分配（No-Write-Allocate）——Store 缺失时绕过缓存直接写下级，与写直达配对。写回 + 写分配是现代 L1/L2/L3 的标准组合；考虑到写缓冲（Write Buffer / Store Buffer）的合并效应（Write Combining），多个连续 Store 可合并为单次缓存行粒度的写回。

### VIPT 与 PIPT 缓存

L1 缓存面临 TLB 访问延迟与缓存访问时间的关键权衡。PIPT（Physically Indexed, Physically Tagged）——Index 和 Tag 都来自物理地址，需先等 TLB 转换才能开始缓存访问，延迟大但无歧义。VIPT（Virtually Indexed, Physically Tagged）——Index 使用虚拟地址低位（页内偏移与物理地址一致），Tag 等待 TLB 转换后的物理地址进行并行比较，是 L1 缓存的标准实现。VIPT 的约束：缓存容量 / 相联度不能超过页大小（4KB）。对于 32KB 8 路缓存，Index = 12 位（恰占满页偏移），满足约束；64KB 需至少 16 路或改用 PIPT。VIVT 虽避免 TLB 访问但引入同义词/反义词（Synonym/Alias）问题，现代处理器基本不用。

### TLB 与虚拟内存

转译后备缓冲器（Translation Lookaside Buffer, TLB）是虚拟地址到物理地址转换的专用缓存。每条 TLB 条目存储 VPN→PPN 映射及权限位（R/W/X）、脏位（Dirty）、访问位（Accessed）。现代处理器有两级 TLB：L1 ITLB/DTLB 各约 32-64 条目，L2 统一 TLB 约 512-2048 条目。TLB 缺失需要硬件页表遍历（Page Table Walk, PTW），4 级 4KB 页表最坏需 4 次内存访问获取物理地址。大页（2MB/1GB Huge Page）显著减少 TLB 缺失；TLB Shootdown 在多核系统中一个核心修改页表时需向其他核心发 IPI 无效化其 TLB。

### 硬件预取

硬件预取器监测访存模式，在程序显式请求前主动将数据加载到缓存中掩盖内存延迟。顺序预取器（Next-Line）对顺序访问有效但浪费带宽于随机访问。步幅预取器（Stride Prefetcher）跟踪每个 PC 的连续两次缺失地址差（步幅）。更高级的方案包括 GHB（Global History Buffer）、SMS（Spatial Memory Streaming）、BOP（Best Offset Prefetching）。预取的三个关键控制参数：预取距离（提前多少步）、预取度（每次触发预取几条行）、预取节流（防止过激预取污染缓存）。现代预取器采用"预取共享"模式以避免不必要地拉取 Exclusive 状态触发的无效化广播。

### 内存层次性能建模

存储层次的性能可以用 AMAT 递归建模。对于 N 级存储层次：AMAT = hit_time_L1 + miss_rate_L1 × (hit_time_L2 + miss_rate_L2 × (hit_time_L3 + miss_rate_L3 × miss_penalty_DRAM))。各级缺失率通常是上一级的局部缺失率（Local Miss Rate），而非全局缺失率。缺失惩罚是递进累积的——L1 缺失的惩罚 = L2 命中时间 + L2 缺失率 × L2 缺失惩罚，依此类推。现代 SoC 中，L1 缺失率约 1-3%（32KB 8 路），L2 缺失率约 10-20%（256KB 8 路），L3/SLC 缺失率约 30-50%（4MB 16 路）。

带宽利用率是另一个关键指标。实际有效带宽 = 峰值带宽 × 利用率。典型利用率受限于 DRAM 的 tFAW（Four Activate Window, 限制 bank 激活速率）、tRFC（Refresh Cycle Time）和各种时序参数导致的"气泡"。DDR5 峰值带宽 51.2 GB/s（单通道 64-bit @ 6400 MT/s），但在随机访问模式下有效带宽可能仅 20-30 GB/s（利用率 40-60%）。HBM 通过宽的 1024-bit 接口和更高的 bank 并行度实现更高的利用率。

### 工作集与缓存容量规划

工作集（Working Set）是程序在时间窗口 Δt 内访问的地址集合。当工作集 <= 缓存容量时，程序经历的主要是强制缺失；当工作集超过缓存容量时，容量缺失率急剧上升——这对应 AMAT 曲线的"拐点"（Knee Point）。拐点之后，每增加一倍缓存容量带来的缺失率改善递减。经典的缓存设计经验法则：缓存容量每翻一倍，缺失率减少一半（平方根规则, Square-Root Rule of Thumb）。但这只在工作集小于缓存容量前成立——一旦容量覆盖了工作集的主要部分，进一步增加容量的改善微乎其微。理解目标负载的工作集大小是缓存容量规划的核心。

### 非阻塞缓存与 MSHR

非阻塞缓存（Non-Blocking Cache）允许缓存在处理一次缺失期间继续服务后续的缓存访问，是实现内存级并行（Memory-Level Parallelism, MLP）的关键硬件机制。其核心数据结构是缺失状态保持寄存器（Miss Status Holding Register, MSHR）。当一次缓存缺失发生时，一个 MSHR 条目被分配，记录缺失地址、目标寄存器号和缺失类型（Load/Store/IFetch）。后续访问如果命中 MSHR 中的缺失地址（即同一缓存行的第二次缺失），会合并到同一 MSHR 条目中而非发起新的下级请求——这称为缺失合并（Miss Merging）。后续访问如果命中缓存或在 MSHR 中无匹配，则正常处理或分配新的 MSHR 条目。

MSHR 的数量直接决定了缓存可同时容忍的未完成缺失数量，进而决定 MLP 的上限。典型 L1 缓存配置 4-8 个 MSHR，L2 缓存配置 16-32 个。MSHR 的溢出条件（所有条目被占用时再次发生缺失）导致缓存必须阻塞新的访存请求直至某个 MSHR 条目释放——这称为 MSHR 资源匮乏（MSHR Starvation），是影响 MLP 上限的关键瓶颈。非阻塞属性通常用两个数字描述，如 "hit under 8 misses, miss under 4 misses"：前者表示在 8 次缺失未解决期间仍可处理缓存命中，后者表示在 4 次缺失未解决期间可继续发起新的缺失请求。

### 缓存的 ECC 与软错误防护

SRAM 缓存在先进工艺节点（≤7nm）面临日益严重的软错误（Soft Error）风险。存储单元电荷状态的随机翻转——由高能粒子（α 粒子或高能中子）撞击芯片引起——可导致缓存数据静默损坏（Silent Data Corruption, SDC）。L1 数据缓存通常采用奇偶校验（Parity）检测 1-bit 翻转——每字节 1 位奇偶位，硬件开销最低但无法纠正错误，检测到后触发精确机器检查异常。L2 和 L3 缓存通常采用单纠错双检错纠错码（Single Error Correction, Double Error Detection, SECDED ECC）——每 64 位数据附加 8 位 ECC 码，可纠正单比特翻转和检测双比特翻转。车规和航空 SoC 可能需要更强的 ECC（如多比特纠正 Chipkill ECC）来满足 ASIL 功能安全需求。

### 缓存直接映射、组相联、全相联的区别

缓存的组织方式由三个参数定义：缓存总容量（C）、块大小（B）、组相联度（N）。三种基本组织方式：直接映射（Direct-Mapped, N=1）——每个内存块仅能放入缓存中的唯一定位（Index 唯一确定），硬件最简单但冲突缺失（Conflict Miss）率最高。当两个频繁访问的地址映射到同一缓存行时产生"乒乓效应"——即使缓存整体仍有大量空闲空间，这两个地址却不断互相驱逐。全相联（Fully-Associative）——任何内存块可放入缓存的任何位置，冲突缺失率为零，但硬件最复杂——每次访问需要将 Tag 与所有缓存行的 Tag 并行比较（需要 CAM 或全并行比较器），仅适用于小容量结构如 TLB（通常 32-128 条目）。组相联（Set-Associative, N-way）——缓存分成 S 个组（Set），每组包含 N 个路（Way）。地址按 Index 确定组号后在组内 N 路中选择一路存放，是实际处理器中的主流方案——L1 数据缓存通常 4-8 路、L2 为 8-16 路、L3/SLC 为 16-20 路。三种组织的本质权衡是"缺失率 vs 硬件复杂度"：全相联缺失率最低但硬件代价最高，直接映射硬件最简但缺失率最高，组相联在两者间取帕累托最优。

缓存命中率的影响因素：(1) 缓存容量——容量越大命中率越高，但遵循"平方根法则"（容量翻倍缺失率减半），收益递减；(2) 块大小——块越大空间局部性利用越好，但过大块增加缺失惩罚（传输时间）且可能将不需要的数据带入缓存造成"污染"；(3) 相联度——增加相联度降低冲突缺失，但增加 Tag 比较器数量和 MUX 延迟；(4) 替换策略——组满时决定淘汰哪个路；(5) 程序访存模式——顺序访问（Stream）和步幅访问（Stride）命中率高，随机访问（Random）和指针追逐（Pointer Chasing）命中率低。

三种缺失类型与缓存参数的关系：强制性缺失（Compulsory / Cold Miss）——首次访问任何块注定缺失，仅受块大小影响（一次取更大的块可减少后续访问的强制性缺失）；容量缺失（Capacity Miss）——工作集超过缓存容量时，即使全相联也无法消除，仅受缓存总容量影响；冲突缺失（Conflict Miss）——不同地址映射到同一组/行导致的缺失，直接映射冲突缺失最多、全相联为零、组相联居中。影响这三者的参数不同——增大容量主要减少容量缺失，增大相联度主要减少冲突缺失，增大块大小主要减少强制性缺失。

替换策略：LRU（Least Recently Used）跟踪每路的访问时间戳淘汰最久未访行——理论最优但 N 路的硬件成本为 O(N log N) 位。伪 LRU（Tree-PLRU）用二叉树近似 LRU——N 路仅需 N-1 位，精度下降约 5-10%。RRIP（Re-Reference Interval Prediction）是现代处理器主流——每路分配 RRPV 值，新行根据策略预设，命中时清零，替换选最高 RRPV 者。RRIP 对扫描模式（Scan）的抵抗力显著优于 LRU——LRU 遇扫描流会将整个组刷成新数据淘汰所有有用行，RRIP 给扫描数据分配高 RRPV 使其在扫描结束后立即成为候选淘汰对象。

写策略：写直达（Write-Through）——Store 同时写缓存和下级存储，保证一致但写流量大；写回（Write-Back）——Store 仅写缓存并标记为脏（Dirty），替换时才写回，写流量大幅减少。写分配（Write-Allocate）——Store 缺失时先将缺失行读入缓存再写入，与写回配对；非写分配（No-Write-Allocate）——Store 缺失时绕过缓存直接写下级，与写直达配对。现代 L1/L2/L3 均采用写回 + 写分配组合。

多级缓存的必要性：单级缓存的"容量-速度"矛盾——大容量 L1 增加访问延迟（Tag 比较和 Data MUX 延迟随容量增大），降低时钟频率；小容量 L1 命中率低导致频繁访问下级存储。多级缓存拆分关注点：L1 优化延迟（小容量、低相联度、VIPT 利用页偏移并行访问）、L2 优化命中率（中等容量和相联度）、L3/SLC 优化容量和共享（大容量、高相联度、所有核心共享）。各级的缺失率以"局部缺失率"度量——访问到达 L2 的请求中仍缺失的比例称为 L2 局部缺失率，全局缺失率从各级累乘得出。

### MMU（内存管理单元）的作用

内存管理单元（Memory Management Unit, MMU）是处理器中负责虚拟地址到物理地址转换的硬件模块。其核心作用是实现虚拟内存系统——让每个进程拥有独立的虚拟地址空间（通常 0 到 2^48-1 字节），与物理内存的实际布局完全解耦。MMU 通过页表（Page Table）维护虚拟页号到物理页帧号的映射关系——页表由操作系统管理并以多级树形结构组织（如 4 级页表：PGD → PUD → PMD → PTE）。当处理器发出一个虚拟地址时，MMU 首先查 TLB——若 TLB 命中则直接获得物理地址；若 TLB 缺失则触发硬件页表遍历（Page Table Walk），逐级访问页表条目直到找到物理页号。页表遍历是昂贵的操作——每级遍历需一次内存访问，4 级页表最坏需 4 次内存访问后才能得到物理地址。

MMU 的第二个核心作用是内存保护。每个页表条目不仅包含物理页帧号，还包含权限位：Read/Write/eXecute 权限、特权级（User vs Supervisor）、Access 位（已访问）和 Dirty 位（已修改）。每次内存访问 MMU 检查权限位——用户态程序尝试访问内核地址触发权限错误（Permission Fault），写入只读页面触发访问错误（Access Fault），执行不可执行页面触发指令错误。这些保护机制是操作系统实现进程隔离的基础——每个进程只能访问其页表中映射的物理页面，非法访问被 MMU 硬件阻止并引发页面错误异常（Page Fault Exception）。

MMU 的第三个核心作用是支持按需分页（Demand Paging）和交换（Swapping）。当程序访问未映射到物理内存的虚拟地址时（页表中 Present 位为 0），MMU 产生页面错误——操作系统的页面错误处理程序将所需页面从磁盘加载到物理内存并建立映射，然后重新执行导致错误的指令。这种机制使得程序可以使用大于物理内存容量的虚拟地址空间。此外，MMU 还支持大页（Huge Page, 2MB/1GB）以显著减少 TLB 缺失——大页将单级页表的覆盖范围从 4KB 扩大到 2MB/1GB，一条 TLB 条目覆盖的地址空间增大了 512 倍/262144 倍。

### 存储层次结构

存储层次结构（Memory Hierarchy）是计算机体系结构中最根本的设计原则——将不同速度、容量和成本的存储技术组织成金字塔结构。从离处理器最近的寄存器堆（<1ns, <1KB）到 L1 缓存（~1ns, 32-64KB）、L2 缓存（~3-5ns, 256KB-1MB）、L3 缓存（~10-15ns, 4-32MB）、主存（DDR DRAM, ~50-100ns, 4-64GB），再到固态硬盘（SSD, ~10-100μs, 256GB-4TB）和机械硬盘（HDD, ~5-10ms, 1-20TB）。每一级容量增大约 10-100 倍但延迟也相应增长——这个金字塔形状不是偶然，而是"速度 × 容量"乘积大致恒定下的必然结构。如果没有存储层次，处理器要么受限于极小容量的快速存储器无法运行大型程序，要么受限于慢速大容量存储器的长延迟导致性能灾难。

存储层次的理论基础是局部性原理。时间局部性——一个地址被访问后短期内很可能再次被访问，这是缓存保留最近访问数据的依据；空间局部性——一个地址被访问后其邻近地址很可能很快被访问，这是缓存以 Block（通常 64 字节）粒度取数的依据。程序中约 90% 的执行时间花费在约 10% 的代码上（指令局部性），数据访问中数组遍历表现出强空间局部性。正是这种局部性使得存储层次的"幻觉"成为可能——处理器大部分时间访问的是快速的小容量 L1 缓存（命中的情况），少数时间才穿透到更大更慢的存储级（缺失的情况）。AMAT（Average Memory Access Time）= hit_time + miss_rate × miss_penalty——只要 miss_rate 足够低，AMAT 可接近最快级的访问时间而整体存储容量接近最慢级。

存储层次还解决了"内存墙"（Memory Wall）问题——处理器速度增长远超内存速度增长导致的性能鸿沟。自 1980 年以来处理器性能增长约 60000 倍，而 DRAM 延迟仅降低约 9 倍（从 200ns 到约 22ns）、带宽增长约 150 倍。存储层次通过在处理器和 DRAM 之间插入多级缓存来"容忍"DRAM 的高延迟——每一级缓存作为 DRAM 的"代理"，将频繁访问的数据保留在离处理器更近的位置，减少了处理器直接与慢速 DRAM 交互的频率。现代 SoC 中，L1 缓存服务于约 98-99% 的访问，L2 服务于约 60-80% 的 L1 缺失，L3/SLC 服务于约 40-60% 的 L2 缺失——只有约万分之一的访问实际到达 DRAM。

### 虚拟内存 — 作用与原理

虚拟内存（Virtual Memory）是操作系统与硬件 MMU 协同提供的抽象——每个进程拥有独立的、从 0 开始的连续虚拟地址空间，与物理内存的实际分布和大小完全解耦。虚拟内存的三大核心作用：(1) 进程隔离——每个进程的页表定义了其可访问的物理内存范围，进程 A 无法访问进程 B 的物理页面（除非显式共享），一个进程的内存错误（如野指针）不会破坏其他进程的数据；(2) 物理内存的高效利用——物理内存被分割为固定大小的页帧（通常 4KB），操作系统按需分配——只有进程实际使用的虚拟页面才映射到物理页帧，计算中的碎片通过换出和页置换回收为连续物理页帧；(3) 超越物理内存容量的程序运行——通过按需分页和交换，程序可使用远大于物理内存大小的虚拟地址空间（如 32 位系统中 4GB 虚拟地址空间使用 512MB 物理内存）。

虚拟内存的实现围绕页表展开——页表是虚拟页号到物理页帧号的映射表。现代 64 位处理器（如 ARMv8/AArch64、x86-64、RISC-V Sv39/Sv48）使用多级页表以避免单级页表的巨大存储开销。以 ARMv8 的 4 级页表为例：48 位虚拟地址分为 Level 0（9 位）→ Level 1（9 位）→ Level 2（9 位）→ Level 3（9 位）→ 页内偏移（12 位）。TTBR0/1（转换表基址寄存器）指向 Level 0 页表，每级索引从当前级页表中选取一个条目指向下一级页表或大页（Block）。页表条目（PTE）的最低 12 位用于属性：有效位（Valid）、读/写/执行权限位（AP[2:1] 和 UXN/PXN）、访问权限（AF）、脏位（Dirty / AP[2] 的组合）、共享性和缓存属性（SH[1:0] 和 AttrIndx[2:0]）。

虚拟内存的关键性能机制：(1) TLB 缓存 VPN→PPN 映射——L1 TLB 通常 32-64 条目、L2 TLB 约 512-2048 条目，命中时 1 周期完成转换；(2) 大页减少 TLB 缺失——2MB 大页使单条 TLB 条目覆盖 512 倍于 4KB 页的地址空间，对数据库和科学计算等大数据集应用至关重要；(3) ASID 避免上下文切换时刷新 TLB——进程切换时无需刷新 TLB，不同进程的条目通过 ASID 区分；(4) 硬件页表遍历器——现代处理器内置硬件状态机自动遍历多级页表填充 TLB，无需操作系统介入每条 TLB 缺失。

## 关键要点

- **AMAT 递归建模**：AMAT = hit_time + miss_rate * miss_penalty，三级缓存需逐级累加
- **三种缺失类型**：强制性（Cold，首次）、容量性（Capacity，工作集超容）、冲突性（Conflict，相联度不足）
- **LRU 最大软肋是扫描模式**：一次扫描淘汰全部有用数据；RRIP 方案已广泛取代纯 LRU
- **VIPT 缓存尺寸上限**：上限 = N_way * page_size，突破需 PIPT 或 Way-Prediction 技术
- **TLB 覆盖范围**：覆盖范围 = 条目数 * 页大小；2MB 大页使覆盖范围扩大 512 倍
- **存储层次的四维权衡**：每级本质上是"容量-延迟-带宽-功耗"四维权衡，不存在单一最优解
- **预取三参数共同决定效率**：预取距离、预取度和节流共同决定效率，过度预取可通过污染导致性能下降
- **CXL 扩展内存**：Type-3 Memory 在 DRAM 和存储间插入新的层次，提供近 DRAM 带宽但延迟高一个数量级
- **MSHR 数量决定 MLP 上限**：L1 通常 4-8 个，L2 通常 16-32 个；MSHR 溢出直接导致缓存阻塞并限制了系统的内存级并行度
- **非阻塞缓存的并行等级**："hit under miss"和"miss under miss"是两个递增的并行等级，后者对硬件的要求显著更高——需多个 MSHR 和更复杂的地址冲突检测
- **缓存 ECC 分级策略**：L1 采用 Parity（1-bit 检测），L2/L3 采用 SECDED ECC（1-bit 纠正 + 2-bit 检测），车规 SoC 需 Chipkill ECC 应对多比特翻转
- **各级缓存访问延迟**：现代处理器 L1 约 3-5 个周期（在 3-5 GHz 下），L2 约 10-15 周期，L3 约 30-50 周期，DDR5 DRAM 约 300-400 周期
- **SECDED ECC 存储开销**：每 64 位数据 8 位 ECC（12.5% 开销），Chipkill ECC（如每 128 位数据 16 位 ECC）可纠正多比特错误和整符号错误
- **缓存分组提升带宽**：将缓存按低地址位分成 2-4 个 Bank，允许每个 Bank 独立并行访问，双倍带宽仅需增加一组 Bank 地址解码逻辑
- **缓存压缩提高有效容量**：如 ARM 的 Pointer-Based Compression 对零值/小值进行模式匹配压缩，有效容量提升 2-3× 但引入压缩/解压缩延迟和碎片化管理开销
- **写合并缓冲区减少写流量**：将多次分散 Store 合并为一次突发写回，显著减少写流量和总线占用
- **一致性缺失惩罚更高于 DRAM**：一致性缺失惩罚 = 目录查询延迟 + 数据从远程核心缓存的传输延迟，典型值 100-300 周期——比 DRAM 访问更长
- **访问模式友好度排序**：顺序访问（Stream）> 步幅访问（Stride）> 随机访问（Random）> 指针追逐（Pointer Chasing），后者 CPI 可能高出前者 10-100 倍
- **SRAM 漏电功耗不容忽视**：在 5nm 以下节点可占总缓存功耗的 30-50%；休眠状态通过降低 SRAM 阵列的电源电压（约 0.6V vs 正常 0.8V-1.0V）减少漏电
- **预取器双重度量标准**：准确度（Accuracy）= 被使用的预取行数 / 总预取行数，覆盖率（Coverage）= 预取消除的缺失数 / 总缺失数，两者共同决定预取效率
- **L1 缓存三元设计折中**：增加容量需要更多 Index 位（VIPT 下受页大小限制）或降低相联度（增加冲突缺失率），延迟-容量-相联度三者互相制约
- **缓存包含策略抉择**：Inclusive（L1 内容总是 L2 子集）简化一致性但浪费容量，Exclusive（L1 与 L2 互斥）最大化有效容量但替换复杂，NINE 是两者的折中方案
- **SRAM（6T单元）静态保持无需刷新**：交叉耦合反相器双稳态存储，有电即保持，访问速度最快（1-10ns），但密度低（每比特6个晶体管）——用于处理器缓存和寄存器堆
- **DRAM（1T1C单元）电容电荷需要刷新**：电容存储电荷会泄漏，必须每64ms刷新一次，密度极高（每比特仅1个晶体管+1个电容），但速度慢于SRAM（tRC约45-55ns）——用于计算机主存
- **Flash和ROM的区别在于可重写性**：ROM（Mask/PROM）不可改写或仅一次编程；Flash基于浮栅晶体管，可反复擦写（10^3-10^5次），但以块/页为擦写单位
- **NOR Flash适合代码存储**：支持按字节随机读取（XIP——代码直接执行），读取延迟约70-100ns，但写入/擦除慢且密度低——用于Bootloader和固件存储
- **NAND Flash适合数据存储**：按页读写、按块擦除，密度极高、成本低——SSD/USB/SD卡的核心存储介质；3D NAND垂直堆叠可达200+层
- **DRAM刷新操作引入带宽开销**：每64ms必须刷新所有行一次，DDR4/DDR5中刷新带宽开销约3-5%，温度升高时刷新周期需缩短（85°C→95°C时tREF从64ms降至32ms）

## 与其他概念的关系

- [[architecture/concepts/缓存一致性|缓存一致性（Cache Coherence）]] — 私有缓存的 MESI 状态转换与写策略、替换策略深度耦合，一致性消息延迟由缓存层次决定
- [[architecture/concepts/乱序执行|乱序执行（Out-of-Order Execution）]] — 乱序执行的 MLP（Memory-Level Parallelism）通过同时容忍多个缓存缺失来掩盖深存储层次的延迟
- [[architecture/concepts/片上总线|片上总线（On-Chip Bus）]] — 缓存缺失和写回事务通过 AXI/CHI 在各级存储间传输，总线延迟直接贡献 miss_penalty，AXI RID/WID 支持 MLP 的事务流水线化
- [[asic-flow/concepts/静态时序分析|静态时序分析（STA）]] — SRAM 缓存阵列的读写时序含 Tag 比较、Data MUX、Way Select 等关键路径，缓存访问时间通常定义处理器时钟周期的下限
- [[concepts/半导体基础|半导体基础（Semiconductor Physics）]] — SRAM的6T单元和DRAM的1T1C存储电容都是MOSFET工艺的产物，漏电机制（亚阈值漏电、结漏电）决定了DRAM的刷新周期和SRAM的静态功耗
- [[asic-flow/concepts/功耗分析|功耗分析（Power Analysis）]] — SRAM的漏电功耗在先进工艺（5nm以下）中占比可达30-50%，DRAM的刷新功耗是内存系统功耗的重要组成部分
- [[architecture/concepts/乱序执行|乱序执行（Out-of-Order Execution）]] — 缓存缺失导致的长时间延迟（miss_penalty）通过 MLP 和 MSHR 在乱序执行中并行容忍
- [[architecture/concepts/指令流水线|流水线（Pipelining）]] — Load-Use Hazard 的阻塞周期与 L1 缓存命中时间直接相关，流水线停顿周期 = L1 命中的延迟
- [[architecture/concepts/SoC架构|SoC 架构（SoC Architecture）]] — DRAM 控制器和 MMU/SMMU 是 SoC 内存子系统的核心 IP——MMU 用于 CPU 侧地址转换，SMMU 用于其他主设备的地址转换
- **直接映射索引 = 地址 mod #行数**：每个地址在缓存中仅有一个固定位置，硬件简单——仅需一个 Tag 比较器和一个 Data MUX——但冲突缺失率最高
- **组相联是先选组再选路**：Index 位选中组（Set），组内 N 路的 Tag 并行比较（N 路比较器）——是缺失率与硬件成本的帕累托最优
- **全相联 Tag 并行比较 N 路**：需 N 个比较器或 CAM 单元——面积和功耗随路数平方增长，仅适用于小容量结构（TLB ≤ 128 条目）
- **三种缺失类型的独立参数影响**：增大容量减少容量缺失、增大相联度减少冲突缺失、增大块大小减少强制性缺失——三者不能互相替代
- **LRU 最大缺陷是扫描模式易失**：一次顺序扫描可淘汰全部有用的热行——RRIP 的 RRPV 分配策略专为解决此缺陷而设计
- **写回 + 写分配是 L1/L2/L3 的标准组合**：写回通过脏位延迟写流量，写分配利用空间局部性——Store 缺失时获取的缓存行很可能在近期被再次访问
- **多级缓存拆分速度与容量关注点**：L1（1-5 周期、32-64KB）关注低延迟；L2（10-20 周期、256KB-1MB）关注快命中；L3（30-50 周期、4-32MB）关注大容量和核间共享
- **AMAT 递归公式量化多级缓存效果**：AMAT = hit_time_L1 + miss_rate_L1 × (hit_time_L2 + miss_rate_L2 × miss_penalty_DRAM)，每级的 miss_rate 是该级的局部缺失率
- **虚拟到物理地址转换是 MMU 的首要使命**：虚拟地址的高位 VPN 通过页表转换为 PPN，低位页内偏移在转换中保持不变
- **TLB 加速地址转换**：TLB 是 VPN→PPN 映射的高速缓存——命中时在 1 个周期内完成转换，缺失时触发多周期页表遍历
- **页表多级结构的原因是页表可能极大**：48 位虚拟地址的全一级页表需 2^36 个 8 字节条目 = 512GB——多级结构仅需为实际使用的虚拟区域分配页表，中间级为空时无需分配
- **权限位实现内存保护**：R/W/X 权限 + User/Supervisor 特权级确保进程隔离——用户程序不能访问内核空间，不能修改只读代码段
- **按需分页使虚拟内存大于物理内存**：仅将活跃页面加载到物理内存，不活跃页面交换到磁盘——程序可使用大于物理内存的虚拟地址空间
- **ASID 避免上下文切换时刷新 TLB**：地址空间标识符（ASID）标记 TLB 条目所属的进程——不同进程的 TLB 条目可共存，切换进程时无需刷新 TLB 全部条目
- **MMU 是 CPU 与内存系统之间的关键路径**：每次指令取指和数据 Load/Store 都经过 MMU——MMU 的延迟直接影响 L1 缓存访问时间，VIPT L1 通过将 TLB 访问与缓存 Index 并行执行来掩盖 MMU 延迟
- **存储金字塔每级遵循 10-100× 容量和延迟梯度**：L1→L2→L3→DRAM→SSD 的延迟比约为 1:3:10:100:10000——各级差异巨大但各司其职
- **局部性原理使存储层次可行**：时间局部性 + 空间局部性 ≈ 90%+ 的 L1 命中率——大部分访问由最快存储级服务
- **AMAT 公式揭示命中率的关键作用**：miss_rate 从 1% 上升到 2% 导致 AMAT 加倍——在 L2 hit_time ≈ 3× L1 hit_time 且 miss_penalty ≈ 30× L1 hit_time 时
- **存储层次是内存墙的工程回应**：处理器性能增长远超内存速度增长——缓存层次将 DRAM 访问频率降低三个数量级
- **寄存器是第零级存储**：编译器通过寄存器分配管理寄存器（通常 32-64 个架构寄存器 + 数十到数百个物理寄存器），0 周期延迟，是存储金字塔的"最顶端"
- **各级容量规划遵循"覆盖工作集"原则**：L1 覆盖热点代码和当前数据（KB 级），L2 覆盖内层循环和近期数据（MB 级），L3 覆盖整个应用的活跃页面（数十 MB 级）
- **虚拟内存三大支柱**：进程隔离（页表权限保护）、内存高效利用（按需分页）、超越物理内存的程序运行（交换）——缺一不可
- **多级页表按需分配中间级**：未使用的虚拟地址区域不需要中间级页表——节省的页表内存空间可达数百 MB 至 GB 级
- **TLB 缺失是虚拟内存的性能代价**：每次 TLB 缺失需 4 次内存访问（4 级页表遍历）——大页、ASID 和硬件页表遍历器是缓解此代价的三大关键机制
- **页错误是虚拟内存的基石**：程序访问未映射地址触发页错误——操作系统将所需页从磁盘加载到内存并建立映射后重试指令，程序对此透明
- **Dirty 位支持高效交换**：页面换出时如果 Dirty 位为 0（未被修改过），可直接丢弃无需写回磁盘——节省了一次磁盘 I/O
- **虚拟地址空间远大于物理内存**：48 位虚拟地址空间为 256TB，而典型物理内存为 8-64GB——仅活跃工作集的页面驻留在物理内存中
- **内核空间 vs 用户空间的虚拟地址划分**：如 ARM64 下通常 TTBR0 管理用户空间（0x0000... - 0x0000FFFF_FFFFFFFF）、TTBR1 管理内核空间（0xFFFF...）——内核空间在所有进程中共享同一页表
