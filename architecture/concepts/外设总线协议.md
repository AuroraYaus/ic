# 外设总线协议

外设总线协议是数字IC系统中连接处理器与外设、存储器的关键接口标准。从板级低速串行总线（SPI/I2C）到高速差分串行链路（PCIe），再到并行存储器接口（DDR），不同协议在带宽、引脚数、延迟和功耗之间做出不同权衡，服务于不同的应用场景。

## 原理

### DDR 工作原理与刷新机制

DDR SDRAM（Double Data Rate Synchronous Dynamic Random Access Memory）是一种同步动态随机存取存储器，其"Double Data Rate"特性指在时钟的上升沿和下降沿各传输一次数据，使数据率是时钟频率的两倍。DDR 的核心存储单元由一个晶体管和一个电容组成（1T1C 结构）——电容存储电荷表示数据位（有电荷 = 1，无电荷 = 0）。由于电容存在漏电效应，存储的电荷会逐渐流失，因此需要定期刷新（Refresh）来保持数据完整性。刷新操作周期性地读出存储单元中的数据并重新写入，补偿漏电导致的电荷损失。DDR 标准规定所有存储单元必须在刷新间隔（tREFI，通常为 7.8μs）内完成一次刷新。刷新以行为单位进行——每次刷新命令同时对一整行（通常 8K-16K 个存储单元）执行刷新操作。

DDR 的操作基于行列地址复用：首先发出行激活命令（ACTIVATE, RAS）选中一行并将其内容加载到行缓冲器（Row Buffer / Sense Amplifier）中，然后发出列读写命令（READ/WRITE, CAS）访问行缓冲器中的特定列，最后通过预充电命令（PRECHARGE）关闭当前行并将数据写回存储单元。Bank（存储体）是 DDR 内部的独立存储阵列——每个 Bank 拥有独立的行缓冲器，不同 Bank 的操作可以交错（Interleaving）以减少访问延迟。DDR4 每个芯片通常有 8 个 Bank（分为 2 或 4 个 Bank Group），DDR5 扩展到 32 个 Bank（8 个 Bank Group），更高的 Bank 并行度提高了有效带宽利用率。

DDR 刷新有三种模式：(1) 自动刷新（Auto-Refresh, AR）——内存控制器周期性发出 REF 命令，DDR 内部自动管理刷新地址。刷新期间 Bank 不可访问，所有 Bank 的刷新窗口为 tRFC（Refresh Cycle Time），DDR4 的 tRFC 为 260-350ns，DDR5 增加到 295-410ns。(2) 自刷新（Self-Refresh）——在低功耗模式下，DDR 内部自行管理刷新而无需外部命令，内存控制器可进入省电状态。(3) 每 Bank 刷新（Per-Bank Refresh）——DDR4/DDR5 支持针对单个 Bank 的刷新（REFpb），被刷新的 Bank 不可访问但其他 Bank 可以继续服务请求，显著降低了刷新对性能的影响。

### SPI 和 I2C 的区别及优缺点

SPI（Serial Peripheral Interface）是 Motorola 定义的四线全双工同步串行通信协议：SCLK（串行时钟，主设备生成）、MOSI（Master Out Slave In，主发从收）、MISO（Master In Slave Out，主收从发）、SS（Slave Select，从设备片选，低有效）。SPI 采用主从架构，通信由主设备主动发起——主设备拉低目标从设备的 SS 线并驱动 SCLK 时钟，每个 SCLK 周期在 MOSI 和 MISO 上各传输一位数据。SPI 支持多种时钟极性和相位组合（CPOL 和 CPHA 共四种模式），可适配不同外设的时序要求。SPI 没有主机仲裁机制，多个从设备各需一根独立的 SS 线——从设备数量增加时引脚数也随之增加。

I2C（Inter-Integrated Circuit）是 Philips/NXP 定义的两线半双工同步串行总线：SCL（串行时钟线）和 SDA（串行数据线），两条线都需上拉电阻至 VDD。I2C 采用主从多主架构——总线上可有多个主设备，通过仲裁机制解决冲突。每个从设备有一个唯一的 7 位或 10 位地址，主设备通过发送目标地址来选择从设备。I2C 定义了标准模式（100 kbps）、快速模式（400 kbps）、快速+（1 Mbps）、高速模式（3.4 Mbps）和超快速模式（5 Mbps）。数据传输以字节为单位，每个字节后跟随一位 ACK/NACK——接收方拉低 SDA 作为应答（ACK），或拉高 SDA 作为非应答（NACK）。

SPI 相对于 I2C 的优势：(1) 全双工——同时收发数据，实际吞吐率是 I2C 的两倍以上；(2) 速度更快——无固定上限，通常可达到数十 MHz（取决于器件和布线），远高于 I2C 的 5 Mbps 上限；(3) 协议开销更低——无地址帧和 ACK 位开销，数据连续传输，效率接近 100%。I2C 相对于 SPI 的优势：(1) 仅需两根线，不随从设备数量增加——在引脚受限的封装中（如 8 脚 MCU）至关重要；(2) 多主设备架构原生支持总线仲裁，无需外部仲裁器；(3) 内置 ACK/NACK 机制——接收方可主动报告错误或未就绪状态，提高通信可靠性；(4) 标准化寻址——支持热插拔和设备发现，适合板级设备管理。

### PCIe 协议基本架构

PCIe（PCI Express）是外围组件互连快速通道标准，是计算机系统中连接 CPU 与 GPU、NVMe SSD、网卡等高性能外设的主流高速串行总线。PCIe 采用分层协议架构——事务层（Transaction Layer）负责端到端的数据传输可靠性：发送端将内存读写和消息请求封装为事务层数据包（Transaction Layer Packet, TLP），TLP 包含头部（地址、请求类型、长度、流量类别（Traffic Class, TC））、数据有效载荷（可选）和可选的端到端 CRC 摘要（ECRC）。TLP 有四种地址路由方式：地址路由（对内存映射 IO 的直接内存访问）、ID 路由（基于 BDF 即 Bus/Device/Function 的标识）、隐式路由（用于根端口到根端口的消息）和接收端口路由。数据链路层（Data Link Layer）提供链路级可靠性：它为自己的数据包（DLLP）添加序列号和链路级 CRC（LCRC），并实现自动重传请求（ACK/NAK）协议——如果接收方检测到 LCRC 错误，则发送 NAK DLLP，发送方从重放缓冲区重新发送该 TLP。物理层分为逻辑子块和电气子块：逻辑子块处理字节条带化/解条带化（在多条通路上分发字节）、8b/10b 或 128b/130b 编码/解码（用于直流平衡和嵌入式时钟）、加扰（减少电磁干扰），以及链路的训练和状态机（LTSSM）——管理链路检测、轮询、配置、恢复和 L0/L0s/L1 低功耗状态。电气子块定义差分信号电平、预加重/去加重（均衡）以及端接。

PCIe 链路由 1 到 16 条通路（Lane）组成，每条通路是一对差分发送和接收对（共 2 个差分对，4 条物理线）。多条通路并行传输时数据按字节条带化——Byte 0 走 Lane 0，Byte 1 走 Lane 1 等等。通路捆绑提供灵活的带宽扩展——PCIe x1（单通路，Gen5 = ~4 GB/s 单向）、x4（~16 GB/s）、x8（~32 GB/s）、x16（~64 GB/s）。每一代 PCIe 数据率翻倍：Gen1 = 2.5 GT/s、Gen2 = 5.0 GT/s、Gen3 = 8.0 GT/s、Gen4 = 16.0 GT/s、Gen5 = 32.0 GT/s、Gen6 = 64.0 GT/s（PAM4 编码）。PCIe 支持功能级复位（Function Level Reset, FLR）、单根 IO 虚拟化（SR-IOV）、地址翻译服务（ATS）和访问控制服务（ACS）等高级特性。

## 关键要点

- **DDR 双倍数据率原理**：在时钟上升沿和下降沿各传输一次数据——2 倍于时钟频率的数据率，数据总线需使用双边沿触发器（DDR FF）捕获
- **1T1C 存储单元决定刷新需求**：电容漏电（约 64ms 的保留时间）迫使所有单元必须定期刷新，漏电速度随温度升高而加快——高温下刷新频率需加倍
- **Bank 交错访问减少延迟**：不同 Bank 的激活和预充电操作可并行和管道化，tRRD（Row-to-Row Delay）和 tFAW（Four Activate Window）限制 Bank 激活速率
- **DDR 时序参数由 JEDEC 标准化**：CAS Latency（CL）、tRCD（RAS-to-CAS Delay）、tRP（RAS Precharge Time）、tRAS（Row Active Time）——四大参数决定了行访问延迟，是内存控制器时序配置的核心
- **DDR5 电压降至 1.1V**：片上电压调节器（VR）将 PMIC 供给的 1.1V 转换为内部所需电压，DDR4 为 1.2V、DDR3 为 1.5V——电压趋势持续下降以降低功耗
- **刷新对性能的影响**：全芯片刷新期间所有 Bank 不可用（tRFC ~300ns），对实时应用（如显示控制器）可能造成不可接受的延迟——每 Bank 刷新将此影响限制在单个 Bank
- **DDR5 引入决策反馈均衡器（DFE）**：在高速（>=4800 MT/s）下通过 DFE 补偿符号间干扰（ISI），从根本上改进了信号完整性
- **SPI 四线全双工 vs I2C 两线半双工**：SPI 速度快但引脚多（每从设备增加 1 根 SS 线加可选的菊花链）；I2C 引脚固定为 2 根但同一时刻只能单向通信
- **SPI 没有标准化的流控机制**：从设备无法主动暂停主设备——需要额外的 READY/BUSY 信号线或软件轮询；I2C 通过时钟拉伸（Clock Stretching）实现从设备反压
- **I2C 仲裁基于 SDA 线"线与"特性**：多个主设备同时启动传输时，发送 1 但检测到 0 的一方仲裁失败并立即释放总线——仲裁不失任何数据，输方可稍后重试
- **SPI 菊花链（Daisy-Chain）模式减少 SS 线**：将从设备的 MISO 接到下一个从设备的 MOSI——形成移位寄存器链，N 个从设备仅需 1 根 SS 线，但需 NxM 位传输来访问所有从设备
- **I2C 总线电容限制**：总线上最多可挂 127 个 7 位地址设备（实际受限于总线电容 <=400pF 和上拉电阻值），总长度一般在数米内
- **SPI 适合高速连续数据流**：ADC/DAC 采样流、LCD 显示帧缓冲、Flash 存储器批量读写——这些场景中 I2C 的地址帧和 ACK 开销造成显著的吞吐率损失
- **PCIe 三层协议架构**：事务层（TLP，端到端可靠性）、数据链路层（DLLP，链路可靠性，ACK/NAK 重传）、物理层（LTSSM，信号完整性）——各层独立运作，正交解耦
- **8b/10b vs 128b/130b 编码**：Gen1/2 使用 8b/10b 编码（20% 开销），Gen3+ 使用 128b/130b 编码（约 1.5% 开销）——显著提高有效带宽利用率
- **LTSSM 管理链路生命周期**：检测、轮询、配置、L0（正常工作）的自动训练序列，支持从 L0 快速进入 L0s（1us 恢复）或更深的 L1（10us 恢复）省电状态
- **流量类别（TC）和虚拟通道（VC）**：最多 8 个 TC 映射到 8 个 VC——不同的 VC 可进行独立流控，高优先级 TC（如等时视频流）不会被低优先级流量阻塞
- **PCIe 拓扑**：根端口（Root Complex）到交换机（Switch）到端点（Endpoint）的树状拓扑，根端口是 CPU/内存域与 PCIe 域的桥——Switch 提供扇出，Endpoint 是最终设备（GPU、NVMe 等）
- **通路条带化**：数据按字节在多条通路间分发，x16 链路的吞吐率理论上等于 16 倍的 x1 吞吐率——条带化/解条带化的对齐由物理层训练时的 Deskew 机制实现
