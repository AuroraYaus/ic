# 时序逻辑

时序逻辑是数字电路的另一半核心——与组合逻辑输出仅取决于当前输入不同，时序逻辑的输出依赖于当前输入**和**历史状态，即电路具有记忆能力。同步时序逻辑以边沿触发的 D 触发器（D Flip-Flop, D-FF）为基本存储单元，在时钟节拍的控制下统一更新状态，构成了现代数字系统的**同步设计范式**（Synchronous Design Methodology）。在同步时序电路中，所有状态寄存器由同一时钟（或经时钟树平衡的多个时钟）驱动，两个寄存器之间的数据通路是纯组合逻辑，时序收敛（Timing Closure）即在预定的时钟周期内确保所有路径的建立/保持时间约束得到满足。这一范式将时序验证问题从"任意状态在任意时刻变化"的模拟电路难题，简化为"相邻寄存器间组合路径延迟小于时钟周期"的静态时序分析（Static Timing Analysis, STA）问题——STA 是整个 ASIC 后端流程的数学基石。

## 原理

### D 触发器的结构与时序参数

D 触发器是边沿触发的单比特存储元件。其核心结构由主从两级锁存器（Master-Slave Latch）构成——当时钟为低时，主锁存器（Master Latch）透明（通过 D 输入），从锁存器（Slave Latch）锁存（保持上一状态）；当时钟上升沿到达时，主锁存器锁存、从锁存器透明，将主锁存器中稳定的数据传递到 Q 输出。典型正边沿触发（Positive Edge-Triggered）的 D-FF 使用传输门（Transmission Gate）或三态门方案实现。

D-FF 的关键时序参数定义了其行为的物理限制。**建立时间（Setup Time, $t_{setup}$）**：在时钟有效沿到达之前，D 输入必须保持稳定的最短时间。建立时间的存在是因为主锁存器采样节点需要时间对 D 输入的电平变化进行充放电，在时钟沿处采样到稳定的值。**保持时间（Hold Time, $t_{hold}$）**：在时钟有效沿到达之后，D 输入必须继续稳定的最短时间。保持时间的存在是因为时钟沿不是无限陡峭的，主锁存器在时钟跳变过程中仍在跟踪 D 输入变化——D 输入过早变化可能被错误地"穿透"到主锁存器。

**时钟到输出延迟（Clock-to-Q Delay, $t_{clk2q}$）**：从时钟有效沿到 Q 输出变为有效值的时间，反映了从锁存器内部节点通过输出驱动级传播到 Q 引脚的延迟。$t_{clk2q}$ 直接增加了数据通路的有效组合逻辑延迟，在时序路径预算中与组合逻辑延迟 $t_{comb}$ 并列。

### 同步时序路径模型

任意两个寄存器之间的一条标准同步时序路径包含三个延迟分量：

$$\text{Path Delay} = t_{clk2q} + t_{comb} + t_{setup}$$

其中 $t_{clk2q}$ 是发射寄存器（Launch FF）的时钟到输出延迟，$t_{comb}$ 是两个寄存器之间所有组合逻辑和互连线的延迟，$t_{setup}$ 是捕获寄存器（Capture FF）的建立时间。时序约束确保：

$$t_{clk2q} + t_{comb\_max} + t_{setup} \leq T_{clk}$$

这是建立时间时序方程——规定了时钟周期的下限。同时保持时间约束确保：

$$t_{clk2q} + t_{comb\_min} \geq t_{hold}$$

这是保持时间时序方程——规定了数据通路的最小延迟下限，限制了两个相邻寄存器的最小距离。

### 同步复位 vs 异步复位

复位的选择（同步 vs 异步）是 RTL 设计中影响面最广的决策之一。**同步复位**将复位信号作为 D 输入端的 MUX 选择条件，复位在时钟沿完成——STA 可精确分析复位释放路径，但需要时钟持续运行。**异步复位**直接连接 D-FF 的异步复位引脚，不依赖时钟即可生效，但复位释放需满足恢复/移除（Recovery/Removal）时序约束，否则触发亚稳态。

> 复位策略的完整方法论（异步断言+同步释放模式、复位同步器与 2-FF CDC 对偶原理、复位树综合、多时钟域复位排序、POR 电路、DFT 兼容性、复位毛刺滤除）参见 [[cross-domain/concepts/复位策略|复位策略（Reset Methodology）]]。

当前业界实践倾向于**异步复位 + 同步释放**（Asynchronous Reset Assertion + Synchronous Deassertion）——复位断言异步完成（确保无时钟条件下可复位），复位释放经过每时钟域的复位同步器（2-FF）同步到时钟沿。在 `always_ff` 中的 RTL 编码模板参见 [[rtl-design/concepts/SystemVerilog|SystemVerilog]] 的 always_ff 复位策略章节。

### 时钟使能（Clock Enable）

时钟使能（Clock Enable, CE）实现有选择地更新寄存器——当 CE=1 时寄存器正常采样 D 输入，CE=0 时寄存器保持上一状态。RTL 实现为 MUX 反馈：`q <= ce ? d : q;`（组合逻辑反馈——在 always_ff 块的 MUX 前馈路径，非组合环路）。综合工具将这一模式推断为 D-FF 的 CE 输入（工艺库中的 D-FF 通常自带 CE 引脚），而非在数据通路上插入额外的 MUX——这样 CE 信号不增加数据通路的延迟，不侵蚀时序预算。

CE 的正确使用：a) CE 的占空比和建立/保持时间必须满足——即 CE 必须在时钟沿前足够早稳定（不晚于 D 输入的建立时间）；b) 综合工具可能将 CE 转换为门控时钟（如果工艺库有 ICG 单元且满足门控条件）——在代码中使用 `always_ff` + CE 模式比手动门控更安全、工具优化的自由度更高。

**时钟使能推断示例**——综合工具将以下两种 RTL 描述推断为相同的 CE 型 D-FF：

```systemverilog
// ============================================================
// 时钟使能（Clock Enable, CE）的两种 RTL 描述方式
// ============================================================
// 两种写法的综合结果完全相同——综合工具识别 CE 模式，映射到
// 工艺库中带 CE 引脚的 D 触发器或插入式时钟门控（ICG）单元
//
// ===== 方式 1：显式 MUX 反馈 —— 综合工具推断 CE 引脚 =====
//
// always_ff @(posedge clk or negedge rst_n)：异步复位 + 时钟上升沿触发
//   - posedge clk    → 时钟上升沿敏感（每个上升沿执行一次）
//   - or negedge rst_n → 异步复位下降沿敏感（rst_n=0 立即复位）
//
// if (!rst_n) ：复位优先级最高——无论 ce 为何值，rst_n=0 时 q 清零
//   - !rst_n 等价于 rst_n == 1'b0（低电平有效复位的标准写法）
//   q <= '0 ：非阻塞赋值 <= 将 q 全部比特清零
//
// else 分支：正常工作模式（rst_n=1 时）
//   q <= ce ? d : q  —— 三元运算符（条件表达式）
//     ce=1 → q <= d  （使能有效：采样新数据 d）
//     ce=0 → q <= q  （使能无效：保持当前值）
//   综合工具将此模式识别为"带 CE 的 D-FF"，而非在数据路径上
//   额外插入 MUX —— CE 信号使用 D-FF 内置的 CE 引脚
always_ff @(posedge clk or negedge rst_n)
    if (!rst_n)
        q <= '0;              // 异步复位：q 清零（全比特置 0）
    else
        q <= ce ? d : q;      // CE 功能：ce=1 采样 d，ce=0 保持 q

// ===== 方式 2：条件赋值 —— 等效推断 =====
//
// else if (ce) q <= d ：仅当 ce=1 时给 q 赋新值
//
// 关键：此处没有写 else 分支——那会不会产生锁存器（Latch）？
//   答案：不会！因为 always_ff 是时序逻辑块——
//   当 ce=0 时 q 不被赋值，意味着"保持 q 的上一个值"
//   这正是触发器的行为：不更新 = 保持状态
//   如果在 always_comb（组合逻辑）中缺 else → 锁存器推断
//   如果在 always_ff （时序逻辑）中缺 else → 保持状态（正常触发器行为）
always_ff @(posedge clk or negedge rst_n)
    if (!rst_n)
        q <= '0;              // 异步复位：q 清零
    else if (ce)
        q <= d;               // 条件更新：ce=1 时才写入 d
    // 隐含: ce=0 时 q 不被赋值 → 保持上一拍的值（D-FF 原生行为）
```

综合工具识别方式 1 和方式 2 为等价的 CE 模式，映射到相同的 ICG 或 CE-FF 单元。方式 1 的显式 `else q <= q` 更清晰表达了"保持状态"的意图，Lint 工具也更友好。

### 时钟门控单元（ICG）

插入式时钟门控单元（Integrated Clock Gating Cell, ICG）是工艺库中专用门控时钟的硬宏单元——内部包含锁存器以避免使能信号（EN）在时钟高电平期间的毛刺传播到门控时钟输出（GCLK）。结构：EN 信号经过低电平透明的锁存器（锁存时钟低电平期间的 EN 值），在时钟高电平时锁存器锁存，其输出与时钟 AND 后产生干净的 GCLK。ICG 消除了 AND 门控的毛刺问题，是综合工具推断时钟门控时的标准映射目标。时钟门控信号（EN）的产生逻辑必须无毛刺（Glitch-Free）——通常为在时钟低电平阶段稳定的组合逻辑输出，或由寄存器直接驱动。

### 多周期路径与虚假路径的时序约束

在复杂数据通路中，并非所有时序路径都需要在单周期内完成。**多周期路径**（Multi-Cycle Path）是指设计者明确允许数据在两个寄存器之间的传播延迟超过一个时钟周期的路径——例如流水线乘法器的第三级输入到第四级输出允许 2 个周期完成。多周期路径约束（`set_multicycle_path`）告诉 STA 工具将建立时间检查推迟到第 N 个时钟沿，避免虚假的时序违例。多周期路径的使用要求：a) 数据的发送端和接收端之间存在明确的协议确保数据在允许的时间窗口内保持稳定；b) 保持时间检查可能需要在更早的时钟沿完成——这是多周期路径约束最常见的配置错误（漏设保持时间多周期约束导致保持时间违例）。

**虚假路径**（False Path）是指物理上存在但功能上不可能发生的数据传输路径——例如跨异步时钟域的路径（已由同步器处理，不应进行同步时序分析）、测试模式下专用 DFT 路径、从不上电的功能模式路径。虚假路径约束（`set_false_path`）将这些路径从 STA 分析中排除，避免 STA 工具在这些路径上浪费优化资源并产生虚假的违例报告。虚假路径的误用（将需要分析的路径错误地设置为 false path）是芯片功能故障的常见根源——每一条 false path 约束必须有明确的功能理由和设计文档记录。

### 多比特寄存器的时序收敛策略

当多比特数据总线从一组寄存器出发，经过组合逻辑到达另一组寄存器时（如 64 位数据通路），不同比特位的组合逻辑深度通常不同——低位比特往往经过少量逻辑（如简单的位操作），高位比特经过更多逻辑层次（如进位链）。这导致不同比特位的数据到达时间（Data Arrival Time）差异显著——称为数据偏斜（Data Skew）。处理数据偏斜的策略：a) **寄存器重定时（Register Retiming）**——综合工具自动将寄存器在组合逻辑中前后移动以均衡路径延迟；b) **有用偏斜（Useful Skew）**——故意调整时钟树使某些寄存器的时钟稍早或稍晚到达，补偿数据路径的延迟差异；c) **流水线插入**——在数据偏斜严重的比特位上多插入一级流水寄存器，使所有比特位同时到达。对于宽总线（>64 位），寄存器重定时通常是面积效率最高的方案，有用偏斜适用于数据偏斜为 5%-15% 时钟周期的场景，流水线插入适用于偏斜严重（>30% 周期）的路径。

### 锁存器与触发器的区别

锁存器（Latch）和触发器（Flip-Flop）都是数字电路中的基本存储元件，但它们的触发机制、行为特性和设计使用场景有本质区别。

锁存器是**电平敏感**（Level-Sensitive）的存储元件——当时钟（或使能）信号为高电平时，锁存器"透明"：D 输入直接传递到 Q 输出，数据路径在此期间连续导通（Transparent Mode）。当时钟为低电平时，锁存器进入锁存模式（Latch Mode）——输出保持时钟下降沿时刻捕获的 D 输入值，不再随输入变化。这种"透明"特性使锁存器在时钟高电平期间像一个导通开关——输入变化立即反映到输出，使得时序分析变得极其复杂（基于电平的时序窗而非边沿的固定时间点）。触发器是**边沿敏感**（Edge-Sensitive）的存储元件——仅在时钟的有效沿（上升沿或下降沿）处采样 D 输入，输出在时钟沿之后更新并保持稳定直到下一个有效沿。触发器的输出在整个时钟周期内不随 D 输入变化，提供了可靠的时序隔离。

物理结构上的差异：锁存器由单个传输门和一个交叉耦合反相器对构成——结构简单、晶体管数量少（约 6-8 个晶体管）。触发器的经典实现是主从结构——由两个级联的锁存器（Master Latch + Slave Latch）构成，主锁存器在时钟低电平时透明，从锁存器在时钟高电平时透明，两级交替工作实现边沿触发——晶体管数量约为锁存器的两倍（约 16-20 个晶体管）。

**设计中必须避免意外锁存器的原因**：（1）锁存器是电平敏感的——STA 工具难以准确建模其时序行为（数据可能在时钟高电平期间的任意时刻透传，且受输入过渡时间和工艺偏斜的影响），导致时序分析的不确定性远大于边沿触发的触发器。（2）锁存器在 DFT 扫描链中不可控——扫描移位模式下锁存器可能在透明期意外通过数据，破坏测试矢量的可控性，降低故障覆盖率。（3）锁存器对输入毛刺极度敏感——时钟使能期间的任何毛刺都会直接透传到输出。（4）综合工具推断出的锁存器来自不完整的 RTL 编码（if 缺 else、case 缺 default），位置和时序不可预测——属于编码缺陷，而非有意设计。

### 同步电路与异步电路

同步电路（Synchronous Circuit）中的所有状态元件（触发器）由统一的全局时钟信号驱动——所有状态更新在相同时钟沿上同步发生。两个触发器之间的数据通路是纯组合逻辑，状态更新和信号传播严格按节拍进行。同步电路的优点：（1）时序验证简化为 STA——每个周期的数据传播延迟只需小于时钟周期，分析可穷举、无测试向量依赖。（2）设计抽象清晰——寄存器边界将电路分割为独立的组合逻辑云，模块间接口基于时钟周期约定。（3）DFT 兼容——扫描链和 ATPG 基于统一的时钟控制。同步电路的缺点：（1）时钟树功耗占总功耗的 30-40%——全局时钟分布网络的充放电是主要功耗来源。（2）最差情况设计——时钟周期必须满足最长路径的延迟，即使其他路径远短于此。（3）时钟抖动和偏斜直接侵蚀时序预算。

异步电路（Asynchronous Circuit）不使用全局时钟——模块间通过本地握手信号（REQ/ACK）协调数据传输。异步电路使用延迟不敏感（Delay-Insensitive）编码（如双轨编码，Dual-Rail Encoding）和完成检测（Completion Detection）逻辑来感知本地计算完成。优点包括：（1）无时钟树功耗——仅在数据实际翻转时消耗能量，空闲时不消耗动态功耗。（2）无时钟抖动/偏斜问题——不存在全局时序收敛的挑战，电路按本地实际延迟步调运行。（3）低电磁干扰（EMI）——无集中时钟沿驱动的同步电流尖峰，辐射谱分散。缺点：（1）设计复杂度高——需要额外的握手逻辑和完成检测电路，面积开销通常 2-3 倍于等价同步设计。（2）缺乏成熟的 EDA 工具支持——异步综合工具和时序分析工具远不如同步流程成熟。（3）测试和调试困难——无统一时钟使得扫描链插入和 ATPG 变得极端复杂。当前工业实践几乎全部使用同步设计范式，异步电路仅用于特定低功耗场景（如事件驱动传感器接口）和前沿研究。

### 用 D 触发器实现分频电路

分频器（Frequency Divider）是数字电路中产生低频时钟或使能信号的基本构建块，其核心是 D 触发器的反馈连接。

**二分频电路（50% 占空比）**：将 D 触发器的反相输出 $\bar{Q}$ 反馈连接到自身 D 输入。在每个时钟上升沿，触发器采样 $\bar{Q}$ 的当前值——若当前 Q=0（$\bar{Q}=1$），下一周期变为 1；若当前 Q=1（$\bar{Q}=0$），下一周期变为 0。由此 Q 输出的翻转频率恰好为输入时钟频率的一半，且占空比天然为 50%。

```systemverilog
// ===== 二分频电路（50% 占空比）=====
// 工作原理：D-FF 的 Q_N 反馈到 D，每个时钟上升沿 Q 翻转一次
//   - Q=0 时，Q_N=1 → D=1 → 下一拍 Q 变为 1
//   - Q=1 时，Q_N=0 → D=0 → 下一拍 Q 变为 0
// 因此每两个时钟周期 Q 完成一次完整翻转 → f_Q = f_clk / 2
//
// always_ff @(posedge clk or negedge rst_n)：异步复位 + 上升沿触发
//   - posedge clk → 每个时钟上升沿采样 D
//   - negedge rst_n → 复位下降沿即刻清零（异步复位）
// if (!rst_n) q   <= 1'b0  → 复位时 q 清零（低电平有效复位）
// else       q   <= ~q    → q 取反后赋给自己（下一个周期翻转）
//   综合工具将此模式推断为一个带反相反馈的 D-FF
//   这是一个脉动分频器（Toggle Flip-Flop, T-FF）的实现
module div2 (
    input  logic clk,      // 输入时钟
    input  logic rst_n,    // 异步复位（低有效）
    output logic clk_div2  // 二分频输出
);
    always_ff @(posedge clk or negedge rst_n)
        if (!rst_n) clk_div2 <= 1'b0;   // 复位：清零
        else        clk_div2 <= ~clk_div2; // 正常：每周期翻转一次
endmodule
```

**三分频电路（50% 占空比）**：三分频（奇数分频）实现 50% 占空比的方法比偶数分频更复杂，因为输出在 1.5 个输入时钟周期内为高、1.5 个周期内为低——而 D-FF 只能在整数时钟沿翻转。核心思路是两个相位差为 180 度的中间分频信号（各自上沿有效），通过 OR 或 AND 合并产生 50% 占空比输出。

```systemverilog
// ===== 三分频电路（占空比 50%）=====
// 设计原理：用两个计数器分别对时钟上升沿和下降沿计数
//   - 上升沿计数 cnt_p  在计数值 0~2 之间循环
//   - 上升沿分频 pos_div：cnt_p < 1 时为高，否则为低
//   - 下降沿计数 cnt_n  在计数值 0~2 之间循环
//   - 下降沿分频 neg_div：cnt_n < 1 时为高，否则为低
//   - 输出 = pos_div AND neg_div → 50% 占空比
// 关键：pos_div 和 neg_div 相位差 180°（分别为上升沿和下降沿生成）
//      它们的 1/3 高电平窗口在时间上错开半个周期
//      AND 后产生 50% 占空比、频率为 clk/3 的输出
//
// DIVFACT ：分频因子（3 = 三分频）
// HALF_DIV ：高电平持续周期数 = 1（对应 50% 占空比：3/2 ≈ 1）
// MAX_CNT  ：计数器最大值 = 2（0、1、2 → 共 3 个状态）
// CNT_W    ：计数器位宽 = 2（ceil(log2(3)) = 2）
module div3 (
    input  logic clk,
    input  logic rst_n,
    output logic clk_div3   // 三分频输出（50% 占空比）
);
    localparam int DIVFACT  = 3;                    // 分频系数：3
    localparam int HALF_DIV = DIVFACT / 2;          // 高电平持续计数：1
    localparam int MAX_CNT  = DIVFACT - 1;          // 最大计数值：2
    localparam int CNT_W    = $clog2(DIVFACT);      // 计数器位宽：2

    logic [CNT_W-1:0] cnt_p; // 上升沿计数器（0 → 2 → 0 → ...）
    logic [CNT_W-1:0] cnt_n; // 下降沿计数器（0 → 2 → 0 → ...）
    logic             pos_div; // 上升沿产生的 1/3 高电平信号
    logic             neg_div; // 下降沿产生的 1/3 高电平信号

    // ===== 上升沿计数器（posedge clk）=====
    // 每个时钟上升沿 cnt_p 加 1（或在 MAX_CNT 时归零）
    // cnt_p 节奏：0→1→2→0→1→2→...
    always_ff @(posedge clk or negedge rst_n)
        if (!rst_n) cnt_p <= '0;
        else        cnt_p <= (cnt_p == MAX_CNT) ? '0 : cnt_p + 1'b1;

    // ===== 下降沿计数器（negedge clk，用 rst_n 取反模拟 negedge 复位）=====
    // 每个时钟下降沿 cnt_n 加 1（或在 MAX_CNT 时归零）
    // 注意：rst_n 为异步信号，不能用于 negedge 触发器的异步复位
    //       实际设计中需要独立的同步复位处理
    always_ff @(negedge clk)
        if (!rst_n) cnt_n <= '0;
        else        cnt_n <= (cnt_n == MAX_CNT) ? '0 : cnt_n + 1'b1;

    // ===== 上升沿分频信号（组合逻辑）=====
    // cnt_p < HALF_DIV 时 pos_div = 1（cnt_p = 0 时高，cnt_p = 1,2 时低）
    // 占空比 = 1/3 ≈ 33%
    assign pos_div = (cnt_p < HALF_DIV) ? 1'b1 : 1'b0;

    // ===== 下降沿分频信号（组合逻辑）=====
    // cnt_n < HALF_DIV 时 neg_div = 1（cnt_n = 0 时高，cnt_n = 1,2 时低）
    // 占空比 = 1/3 ≈ 33%
    assign neg_div = (cnt_n < HALF_DIV) ? 1'b1 : 1'b0;

    // ===== 最终输出：pos_div AND neg_div → 50% 占空比 =====
    // pos_div 在 clk 上升沿后变高（持续 1 周期）
    // neg_div 在 clk 下降沿后变高（持续 1 周期）
    // 两者 AND 后：高电平覆盖 1.5 个周期（50% 占空比）
    assign clk_div3 = pos_div && neg_div;
endmodule
```

**奇数分频通用方法**：对于任意奇数 N，50% 占空比分频的通用方法：用模 N 计数器分别对时钟上升沿和下降沿计数，上升沿触发信号在计数值 < (N-1)/2 时为高，下降沿触发信号同样在计数值 < (N-1)/2 时为高——两个信号的 AND（或 OR，取决于相位对齐方式）产生 50% 占空比。对于偶数分频，50% 占空比直接通过 D-FF 反馈链实现——级联 n 级触发器的输出频率为 $f_{clk} / 2^n$，但需要额外的复位逻辑控制初始相位。

**小数分频**：小数分频（如 3.5 分频）需要更复杂的方法——常见方案是使用双模分频器（Dual-Modulus Prescaler）在 N 和 N+1 之间切换，通过 Sigma-Delta 调制器控制切换序列的平均频率达到精确的小数分频比。例如，3.5 分频可以通过交替执行 3 分频和 4 分频，平均每 2 个输出周期包含 7 个输入周期（7/2 = 3.5）。

**分频器与时钟倍频器的区别**：分频器降低频率（输出频率 = 输入频率 / N），仅用数字逻辑（D-FF + 反馈）即可实现。倍频器（Clock Multiplier）提高频率（输出频率 = 输入频率 * N），必须依赖模拟电路——PLL（锁相环）通过相位比较器和压控振荡器（VCO）将低频参考时钟锁定到高频输出。分频器是纯数字的（综合友好），倍频器是混合信号的（需要模拟设计）。在 SoC 中，PLL 内部使用高频 VCO（如 2-5 GHz），再通过可编程数字分频器产生各模块所需的不同频率——分频器生成的时钟称为生成时钟（Generated Clock），在 STA 中需要用 `create_generated_clock` 准确定义。

### 同步电路与异步电路的对比

同步电路（Synchronous Circuit）中的所有状态元件由统一的全局时钟驱动——所有状态更新在相同时钟沿同步发生，这是现代数字设计的绝对主流范式。同步电路的压倒性优势在于时序验证可简化为 STA——每个周期内组合逻辑延迟 < 时钟周期即可保证功能正确。STA 无需测试向量即可穷举分析所有路径，提供 100% 覆盖率——这是同步范式已被工程界完全采纳的根本原因。

异步电路（Asynchronous Circuit）不使用全局时钟，模块间通过本地握手信号（REQ/ACK）协调。优点包括：无时钟树功耗、无时钟抖动/偏斜问题、低 EMI。但代价显著：设计复杂度高（需额外握手和完成检测电路）、EDA 工具支持不成熟、DFT 测试困难。当前工业实践几乎全部使用同步设计范式，异步电路仅用于特定超低功耗传感器接口等场景。

## 关键要点

- **D-FF 三个基础时序参数**：建立时间（$t_{setup}$）+ 保持时间（$t_{hold}$）+ 时钟到输出（$t_{clk2q}$）定义同步时序路径的上下限
- **建立+保持双方程决定时钟**：建立方程 $t_{clk2q} + t_{comb\_max} + t_{setup} \leq T_{clk}$ 决定时钟频率上限，保持方程 $t_{clk2q} + t_{comb\_min} \geq t_{hold}$ 决定两个寄存器的物理最小间距
- **异步复位 + 同步释放为实用方案**：异步断言 + 各域复位同步器释放，兼顾上电复位能力和时序安全性
- **时钟使能通过 MUX 反馈推断**：always_ff 中的 MUX 反馈模式被综合工具映射到 D-FF 内部 CE 引脚，不额外消耗数据通路时序预算
- **ICG 内部锁存器消除毛刺**：集成时钟门控单元内部锁存器消除门控输出毛刺，优于手动 AND 门控，是综合工具推荐的时钟门控映射目标
- **同步 vs 异步复位的时序代价**：同步复位可被 STA 精确分析但需要运行时钟，异步复位不需要时钟但引入 Recovery/Removal 时序检查
- **主从锁存器实现边沿触发**：D-FF 的主从锁存器结构（Master-Slave Latch）是实现边沿触发的物理基础——主锁存器采样 D 输入，从锁存器在边沿后传递稳定值
- **STA 全角全模验证消除违例**：建立/保持时间违例导致的亚稳态在同步时序设计中应被完全消除，STA 在 Signoff 时对所有时序路径的建立/保持进行全角全模验证
- **多周期和虚假路径需文档记录**：多周期路径（set_multicycle_path）和虚假路径（set_false_path）是时序约束的关键调节手段，每一条约束必须有明确的功能理由和文档记录
- **数据偏斜三种解决策略**：多比特宽总线中数据偏斜不可避免，寄存器重定时、有用偏斜和流水线插入是三种互补策略，分别适用于不同偏斜幅度的场景
- **抖动与偏斜是独立概念**：时钟抖动（Clock Jitter）是时钟周期的逐周期变化（时序不确定性），时钟偏斜（Clock Skew）是同一时钟到达不同寄存器的空间延迟差异（物理分布），两者都在 STA 中以时序裕量预算的形式体现

## 与其他概念的关系

- [[rtl-design/concepts/组合逻辑|组合逻辑]] — 时序路径的两个端点之间是组合逻辑（$t_{comb}$），组合逻辑的路径延迟和 D-FF 时序参数共同决定时钟频率和时序约束。组合逻辑的扇出（Fanout）过大导致过渡时间增加，反过来劣化捕获寄存器的 $t_{setup}$ 约束——这是组合逻辑与时序参数之间的非直觉耦合关系
- [[concepts/亚稳态|亚稳态（Metastability）]] — 建立/保持时间违例导致的亚稳态是异步信号跨时钟域（CDC）的物理根源。同步时序域内违反建立/保持时间的后果是确定性的功能错误（采样到错误值），而跨时钟域的亚稳态是概率性的——两者的处理方式和设计保证手段完全不同
- [[rtl-design/concepts/跨时钟域设计|CDC 设计]] — 同步器和复位同步器的结构基于 D-FF 的时序参数和亚稳态解析时间。2-FF 同步器的可靠性保证（MTBF）建立在 D-FF 的解析时间常数 $\tau$ 和增益带宽积的物理特性之上——先进工艺节点的 $\tau$ 减小，同步器可靠性提升
- [[asic-flow/concepts/静态时序分析|静态时序分析（STA）]] — 时序路径方程是 STA 的数学模型基础——STA 对所有寄存器的 $t_{setup}$、$t_{hold}$ 和 $t_{clk2q}$ 进行全角分析。Setup 违例可通过降低频率或优化组合逻辑解决，Hold 违例与频率无关（必须通过增加数据路径延迟或减少时钟偏斜解决）——这是很多设计者到 Signoff 阶段才意识到的关键认知
