# 时序逻辑（Sequential Logic）

时序逻辑是数字电路的另一半核心——与组合逻辑输出仅取决于当前输入不同，时序逻辑的输出依赖于当前输入**和**历史状态，即电路具有记忆能力。同步时序逻辑以边沿触发的 D 触发器（D Flip-Flop, D-FF）为基本存储单元，在时钟节拍的控制下统一更新状态，构成了现代数字系统的**同步设计范式**（Synchronous Design Methodology）。在同步时序电路中，所有状态寄存器由同一时钟（或经时钟树平衡的多个时钟）驱动，两个寄存器之间的数据通路是纯组合逻辑，时序收敛（Timing Closure）即在预定的时钟周期内确保所有路径的建立/保持时间约束得到满足。这一范式将时序验证问题从"任意状态在任意时刻变化"的模拟电路难题，简化为"相邻寄存器间组合路径延迟小于时钟周期"的静态时序分析（Static Timing Analysis, STA）问题——STA 是整个 ASIC 后端流程的数学基石。

## 原理

### D 触发器的结构与时序参数

D 触发器是边沿触发的单比特存储元件。其核心结构由主从两级锁存器（Master-Slave Latch）构成——当时钟为低时，主锁存器（Master Latch）透明（通过 D 输入），从锁存器（Slave Latch）锁存（保持上一状态）；当时钟上升沿到达时，主锁存器锁存、从锁存器透明，将主锁存器中稳定的数据传递到 Q 输出。典型正边沿触发（Positive Edge-Triggered）的 D-FF 使用传输门（Transmission Gate）或三态门方案实现。

D-FF 的关键时序参数定义了其行为的物理限制。**建立时间（Setup Time, $t_{setup}$）**：在时钟有效沿到达之前，D 输入必须保持稳定的最短时间。建立时间的存在是因为主锁存器采样节点需要时间对 D 输入的电平变化进行充放电，在时钟沿处采样到稳定的值。**保持时间（Hold Time, $t_{hold}$）**：在时钟有效沿到达之后，D 输入必须继续稳定的最短时间。保持时间的存在是因为时钟沿不是无限陡峭的，主锁存器在时钟跳变过程中仍在跟踪 D 输入变化——D 输入过早变化可能被错误地"穿透"到主锁存器。

**时钟到输出延迟（Clock-to-Q Delay, $t_{clk2q}$）**：从时钟有效沿到 Q 输出变为有效值的时间，反映了从锁存器内部节点通过输出驱动级传播到 Q 引脚的延迟。$t_{clk2q}$ 直接增加了数据通路的有效组合逻辑延迟，在时序路径预算中与组合逻辑延迟 $t_{comb}$ 并列。

### 同步时序路径模型

任意两个寄存器之间的一条标准同步时序路径包含三个延迟分量：

$$\text{Path Delay} = t_{clk2q} + t_{comb} + t_{setup}$$

其中 $t_{clk2q}$ 是发射寄存器（Launch FF）的时钟到输出延迟，$t_{comb}$ 是两个寄存器之间所有组合逻辑和互连线的延迟，$t_{setup}$ 是捕获寄存器（Capture FF）的建立时间。时序约束确保：

$$t_{clk2q} + t_{comb\_max} + t_{setup} \leq T_{clk}$$

这是建立时间时序方程——规定了时钟周期的下限。同时保持时间约束确保：

$$t_{clk2q} + t_{comb\_min} \geq t_{hold}$$

这是保持时间时序方程——规定了数据通路的最小延迟下限，限制了两个相邻寄存器的最小距离。

### 同步复位 vs 异步复位

复位的选择（同步 vs 异步）是 RTL 设计中影响面最广的决策之一。

**同步复位（Synchronous Reset）**：复位信号仅作为 D 输入端的组合逻辑条件（`always_ff @(posedge clk) if (rst) q <= 0;`），复位释放在时钟沿同步完成。优点：STA 可精确分析复位-释放路径——复位释放在时钟沿完成，不会产生复位释放与时钟沿之间的亚稳态风险；时序路径清晰，可完全约束；没有异步复位释放的恢复/移除（Recovery/Removal）时序检查。缺点：需要时钟在复位期间保持运行（没有时钟则无法采样复位）；增加数据通路的组合逻辑（reset 是 MUX 的选择输入）；在门级网表中需要更多的逻辑门。

**异步复位（Asynchronous Reset）**：复位信号直接连接到 D-FF 内部的异步复位输入——不受时钟控制。优点：即使没有时钟也能复位（上电复位场景）；不增加数据通路的组合逻辑（复位路径独立于数据通路）；综合工具优化效果更好。缺点：复位释放在随机时刻——如果复位释放沿靠近时钟沿，FF 可能进入亚稳态（需要复位同步器）；引入额外的恢复（Recovery）和移除（Removal）时序检查——类似于建立/保持但用于异步复位输入相对于时钟沿的时间裕量；DFT 扫描测试中异步复位的处理更复杂。

当前业界实践倾向于**异步复位 + 同步释放**（Asynchronous Reset Assertion + Synchronous Deassertion）——复位断言（低电平有效）异步完成，确保无时钟条件下可复位；复位释放经过每时钟域的复位同步器（2-FF Synchronizer）同步到时钟沿，确保释放后的第一拍所有 FF 同步启动。这是两方案优势兼顾的实用方案。

### 时钟使能（Clock Enable）

时钟使能（Clock Enable, CE）实现有选择地更新寄存器——当 CE=1 时寄存器正常采样 D 输入，CE=0 时寄存器保持上一状态。RTL 实现为 MUX 反馈：`q <= ce ? d : q;`（组合逻辑反馈——在 always_ff 块的 MUX 前馈路径，非组合环路）。综合工具将这一模式推断为 D-FF 的 CE 输入（工艺库中的 D-FF 通常自带 CE 引脚），而非在数据通路上插入额外的 MUX——这样 CE 信号不增加数据通路的延迟，不侵蚀时序预算。

CE 的正确使用：a) CE 的占空比和建立/保持时间必须满足——即 CE 必须在时钟沿前足够早稳定（不晚于 D 输入的建立时间）；b) 综合工具可能将 CE 转换为门控时钟（如果工艺库有 ICG 单元且满足门控条件）——在代码中使用 `always_ff` + CE 模式比手动门控更安全、工具优化的自由度更高。

### 时钟门控单元（ICG）

插入式时钟门控单元（Integrated Clock Gating Cell, ICG）是工艺库中专用门控时钟的硬宏单元——内部包含锁存器以避免使能信号（EN）在时钟高电平期间的毛刺传播到门控时钟输出（GCLK）。结构：EN 信号经过低电平透明的锁存器（锁存时钟低电平期间的 EN 值），在时钟高电平时锁存器锁存，其输出与时钟 AND 后产生干净的 GCLK。ICG 消除了 AND 门控的毛刺问题，是综合工具推断时钟门控时的标准映射目标。时钟门控信号（EN）的产生逻辑必须无毛刺（Glitch-Free）——通常为在时钟低电平阶段稳定的组合逻辑输出，或由寄存器直接驱动。

## 关键要点

- 建立时间（$t_{setup}$）+ 保持时间（$t_{hold}$）+ 时钟到输出（$t_{clk2q}$）是 D-FF 的三个基础时序参数——定义同步时序路径的上下限
- 时序路径方程：$t_{clk2q} + t_{comb\_max} + t_{setup} \leq T_{clk}$（建立）和 $t_{clk2q} + t_{comb\_min} \geq t_{hold}$（保持）——前者决定时钟频率上限，后者决定两个寄存器的物理最小间距
- 异步复位 + 同步释放（异步断言 + 各域复位同步器释放）是兼顾上电复位能力和时序安全性的实用方案
- 时钟使能（CE）通过 always_ff 中的 MUX 反馈模式推断——综合工具映射到 D-FF 内部 CE 引脚，不额外消耗数据通路时序预算
- ICG（集成时钟门控单元）内部锁存器消除门控输出毛刺——优于手动 AND 门控，是综合工具推荐的时钟门控映射目标
- 同步复位可被 STA 精确分析但需要运行时钟，异步复位不需要时钟但引入 Recovery/Removal 时序检查
- D-FF 的主从锁存器结构（Master-Slave Latch）是实现边沿触发的物理基础——主锁存器采样 D 输入，从锁存器在边沿后传递稳定值
- 建立/保持时间违例导致的亚稳态在同步时序设计中应被完全消除——STA 在 Signoff 时对所有时序路径的建立/保持进行全角全模验证
