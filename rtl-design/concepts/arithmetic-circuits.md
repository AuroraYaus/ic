# 算术电路（Arithmetic Circuits）

算术电路是数字系统中执行加、减、乘、除和移位等基本算术运算的专门硬件单元，位于几乎所有芯片数据通路的性能关键路径上。算术电路的硬件实现选择——从简单的行波进位加法器（RCA）到复杂的 Booth-Wallace 乘法器——直接决定了运算单元的延迟、面积和功耗，进而影响整个系统的时钟频率和能效比。现代综合工具可以自动从 RTL 中的 `+`、`*` 运算符推断硬件结构，但了解底层算法和实现结构对于性能优化（如设置综合约束指导工具选择乘法器架构）、定制设计（如设计高性能定点 DSP 加速器）和性能瓶颈分析是必要的。算术电路设计是典型的面积-速度-功耗三方权衡优化问题，不存在"最优方案"——选择取决于具体的设计约束。

## 原理

### 加法器：从半加器到超前进位

加法器是所有算术运算的基石——减法通过补码加法实现，乘法通过多操作数加法实现，比较通过减法实现。

**半加器（Half Adder, HA）**：输入 A 和 B 两个 1 位操作数，输出 Sum = A^B（XOR）和 Cout = A&B（AND）。半加器只能处理两个输入比特，不能接受进位输入，一般只在 CSA 树的最终压缩中使用。

**全加器（Full Adder, FA）**：输入 A、B 和进位输入 Cin，输出 Sum = A^B^Cin 和 Cout = (A&B) | (A&Cin) | (B&Cin)（多数决 Majority Function）。N 位全加器 = 1 个半加器 + (N-1) 个全加器和进位链。

**行波进位加法器（Ripple-Carry Adder, RCA）**：N 个 1 位全加器串联，每级加法器的进位输出连接到下一级的进位输入。面积最小（N 个 FA），但延迟为 O(N)——最坏情况下进位从最低位传播到最高位（进位 = 111...1）。RCA 适用于低位数（<8 位）或非关键路径（如地址生成器）。

**超前进位加法器（Carry-Lookahead Adder, CLA）**：通过并行计算进位生成信号（Generate, G_i = A_i & B_i）和进位传播信号（Propagate, P_i = A_i ^ B_i），使用树形结构预先计算所有位的进位。基本 CLA 的延迟为 O(log N)，面积约 2-3 倍于 RCA。实际 CLA 采用混合层次结构——每组 4-8 位用 CLA 计算组内进位，组间用 RCA 或更高层 CLA 级联——兼顾速度和面积。

**进位选择加法器（Carry-Select Adder, CSelA）**：将加法器分为若干组，每组准备两个版本——一个假设进位输入为 0，一个假设进位输入为 1——并行计算两种结果，当上游进位到达时通过 MUX 选择正确输出。延迟为 O(sqrt(N)) 或 O(log N)，面积比 RCA 大约 1.5 倍，是 ASIC 数据通路的常用折中方案。

**进位保留加法器（Carry-Save Adder, CSA/3:2 Compressor）**：将三个输入比特压缩为两个输出比特（Sum 和 Carry），不跨位传播进位（Carry 被"保存"到下一级而不立即合并）。CSA 的延迟与操作数位宽无关（常数延迟），是多操作数加法（部分积累加）的核心构件。3:2 CSA 是 Wallace 树和 Dadda 树的基本压缩单元，4:2 Compressor（5 输入 3 输出）是更高级的压缩块（一次压缩更多操作数层）。

### 乘法器：Booth 编码与树形压缩

N 位乘法产生 N 个部分积（Partial Product），部分积累加决定最终乘积。基本的阵列乘法器 N 行 M 列的 FA 形成二维进位保存阵列，延迟 O(N)，面积 O(N^2)。

**Booth 编码（Booth Encoding）**：Booth 算法通过重叠扫描乘数位来减少部分积数量。**Radix-2 Booth** 检查当前位和前一位，产生 {-1, 0, +1} 倍的被乘数部分积，但部分积数量不减少（仍约 N 个）。**Radix-4 Booth（Modified Booth）** 同时扫描 3 位（当前 2 位交叠 1 位），编码为 {-2, -1, 0, +1, +2}，将部分积数量减半至 N/2。±2 倍通过左移 1 位实现（无实际乘法），±1 倍是被乘数本身或补码，0 倍是零——所有部分积生成仅需要移位、取反和选通。Radix-4 Booth 将部分积从 N 个减至约 N/2 个（若 N 为奇数则 (N+1)/2），将后续部分积压缩树的深度减半，延迟和面积都显著降低。更高 radix 的 Booth（radix-8）部分积更少但需要 ±3 倍的预计算（需要一次加法），通常不值得——radix-4 Booth 是现代乘法器的最优编码层数。

**Wallace 树（Wallace Tree）**：将部分积压缩到两操作数（Sum 和 Carry）的层数最小化策略。Wallace 树使用 3:2 CSA 作为基本构件，将每层的操作数数量减少约 1/3——每三个操作数被压缩为两个。层数约 log_{1.5}(N_partial) ≈ O(log N)。延迟约 O(log N)，但布线不规则，导致版图面积中的连线和沟道开销大。

**Dadda 树（Dadda Tree）**：与 Wallace 树相同原理下的优化策略——不是将所有可压缩组都压缩，而是仅在操作数数量超过下一层目标数量时才压缩，从而减少 CSA 的总数（面积略小），延迟与 Wallace 树相同。Dadda 树比 Wallace 树在面积上有轻微优势，在 ASIC 数据通路中更为常用。

**最终 CPA**：压缩到两操作数后，需要一次完整的进位传播加法（Carry-Propagate Adder, CPA）将 Sum 和 Carry 合并为最终二进制乘积。CPA 可使用 CLA、CSelA 或前缀加法器（Kogge-Stone、Brent-Kung），其延迟决定了乘法器的最终总延迟中不可再压缩的部分。

### 除法器

除法是四种基本运算中硬件最复杂的操作，不同算法的性能和面积差异巨大：

**恢复余数除法（Restoring Division）**：基本"试商-减-判断-恢复"循环——每一步用部分余数减去除数，若结果为负则"恢复"（加回除数）并将商位置 0，否则保留并将商位置 1。每比特需一次减法（或减法+恢复加法），N 比特除法需要 N 至 2N 个周期。硬件简单（一套加减器+移位器），但速度慢。

**不恢复余数除法（Non-Restoring Division）**：改进了恢复除法——负数结果不加回除数，而是在下一步加上除数（而非减去）。每一步恰好执行一次加法或减法（不恢复），固定 N 个周期。面积与恢复除法相同，速度约为其 1.5 倍。配合符号位处理的变体支持有符号除法。

**SRT 除法（Sweeney-Robertson-Tocher Division）**：高基数（Radix-4 或 radix-8）除法，每步生成多个商位（而非一位）。使用商数选择表（商位 LUT）根据部分余数高位的估计值快速选择商位，每步一次加/减+移位。延迟约为 O(N/k)（k 为基数的对数），是现代处理器除法器的标准方案。

**Goldschmidt 和 Newton-Raphson 除法**：迭代逼近法——将除法转化为乘法序列，利用浮点乘法器已有硬件。Goldschmidt 除法通过分子分母同时乘以收敛因子逼近 1/D；Newton-Raphson 通过迭代解 f(x) = 1/x - D = 0。延迟低（乘法的 2-3 倍），但需要初始近似值（查表），适用于已有高速乘法器的浮点单元。

### 桶形移位器

**桶形移位器（Barrel Shifter）** 是可以在单周期内完成任意位移位（左移、右移、算术右移、循环移位）的组合电路。N 位桶形移位器使用 log2(N) 层 2:1 MUX——第 k 层 MUX 选择"不移位"或"移位 2^k 位"，移位量控制信号逐层选择。延迟 O(log N)，面积 O(N·log N)。桶形移位器是 ALU 数据通路中除乘法器外面积最大的组合单元——例如 64 位桶形移位器包含 64×6 = 384 个 MUX。综合工具通常使用专用移位器结构，但对于大位宽数据通路，设计者可能需要通过流水线插入来改善移位器的时序收敛。

## 关键要点

- 加法器选择取决于位宽和时序约束：RCA（N<8 或非关键路径）、CLA（N=8-32）、CSelA（N=16-64，ASIC 大位宽泛用方案）、前缀加法器（N>32，速度最优）
- 补码减法通过 A - B = A + (~B + 1) 实现——取反和加 1 在加法器最低位进位端完成，无需独立的减法器
- Radix-4 Booth 编码将部分积数量减半至 N/2，是现代乘法器的标准编码层——更高 radix 因 ±3 预计算开销不值得
- Wallace/Dadda 树通过 3:2 CSA 将 O(N) 个部分积在 O(log N) 层内压缩为两个操作数，延迟和面积吞吐率远优
- 除法器架构选择：N 位简单除法用非恢复除法（N 周期）、高性能处理器用 SRT radix-4/8 除法、浮点单元用 Goldschmidt/Newton-Raphson 迭代除法
- 桶形移位器是组合移位单元，log2(N) 层 MUX 结构确保任意移位量在 O(log N) 延迟内完成——高位数大位宽移位器通常需要流水线化
- 算术运算的溢出检测：有符号加法的溢出发生在两个同号操作数结果符号相反时（最高位进位 XOR 次高位进位）
- 综合工具从 RTL 中的 `+` 和 `*` 运算符通常能生成合理硬件——但大位宽乘法需要明确选择 Booth/Wallace 架构约束
- 有符号/无符号算术混用（signed/unsigned）在 Verilog 中需显式使用 `$signed()` 或声明 signed 类型——无符号算术用零扩展、有符号用符号扩展
- 算术电路流水线化时，CSA/Wallace/压缩树的中间节点是天然的寄存器切片位置——利用部分积之间的自然并行度降低了流水线开销
