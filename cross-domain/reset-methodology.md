# 复位方法学（Reset Methodology）

复位（Reset）是数字系统中将电路强制置入已知初始状态的机制。复位设计看似简单，但在大规模 SoC 中涉及同步-异步选择、复位树的时序收敛、多时钟域复位排序、DFT 兼容性和功耗控制等多个维度——不当的复位设计是芯片死机（Deadlock）、不定态传播（X-propagation）、和硅后调试困难的常见根源。

## 原理

### 同步复位

同步复位（Synchronous Reset）在每个 DFF 的数据输入端通过 AND 门或 MUX 与复位信号组合，复位仅在时钟边沿生效。SystemVerilog 编码模式：`always_ff @(posedge clk) if (!rst_n) q <= 1'b0; else q <= d;`。优点：100% 同步时序——不引入任何异步路径，STA 可完全分析复位到输出的延迟，复位信号无需特殊处理即可被时钟自然屏蔽毛刺（Glitch），DFT 扫描模式下复位完全由时钟控制。缺点：（1）时钟未运行时复位完全无效——这是同步复位的致命缺陷，因为上电阶段时钟振荡器尚未稳定启动，同步复位无法在这期间产生作用；（2）复位逻辑纳入数据路径增加 DFF 数据输入端的扇入（Fan-In），可能成为关键时序路径的瓶颈；（3）需要额外的时钟门控单元确保即使在复位期间时钟持续运转，否则 DFF 可能漏采复位事件。

### 异步复位

异步复位（Asynchronous Reset）直接连接到 DFF 的异步复位/置位引脚（`always_ff @(posedge clk or negedge rst_n)`），复位不依赖时钟沿，电平敏感、立即生效。优点：时钟未运行时也生效——这是 POR 阶段的关键需求；不复用数据路径因此不增加 DFF 数据输入端负载；DFF 复位输入本身就是异步的，不引入组合逻辑延迟。缺点：（1）复位释放（Reset Release / Deassertion）——如果异步复位撤销信号的边沿与时钟沿距离过近，违反恢复时间（Recovery Time, Trem）或移除时间（Removal Time, Tremov），DFF 将进入亚稳态；（2）异步复位对毛刺极度敏感——复位输入上的即便是一个短暂的噪声脉冲也会触发全系统复位；（3）异步复位路径不在 STA 的常规时序分析内，需要专门的恢复/移除时序检查（`.lib` 中的 `recovery` 和 `removal` 时序弧）。

### 异步断言 + 同步解断言模式

业界标准的复位方案是异步断言 + 同步解断言（Asynchronous Assert, Synchronous Deassert），结合了两者的优势：上电和异常时异步即时进入复位状态，但复位释放被时钟边沿同步化以消除恢复/移除时序违规。实现的电路为复位同步器（Reset Synchronizer）：外部异步复位信号（POR 输出或外部管脚）异步置位两级串联的 DFF，DFF 输入端固定接高电平（1'b1）；当外部复位信号释放时，第一级 DFF 在紧接的时钟沿采样高电平解除复位，经过一个时钟周期的解析时间后第二级 DFF 跟随解除。两级 DFF 的输出即"同步化"的复位信号——确保释放边沿相对于目标时钟满足 Removals/Recovery 时序要求。

复位同步器与 2-FF CDC 同步器原理完全对偶——第一级 DFF 承担亚稳态风险（复位释放与时钟沿可能位于恢复/移除窗口内），第二级 DFF 输出干净的已同步复位信号。关键设计要点：同步器的两级 DFF 之间无组合逻辑（保持最大解析时间预算），且 DFF 必须使用带异步复位/置位引脚的单元（异步复位端接外部复位，数据端接 VDD）。

### 复位树与分布

复位信号需要分发到芯片上成千上万个 DFF，形成复位树（Reset Tree）。缓冲复位树采用类似时钟树综合（CTS）的策略——插入多级缓冲器平衡至多个加载端的延迟，使所有 DFF 在同一时钟沿附近解除复位，避免不同 DFF 解除复位的时间差异导致不定态交互。在大规模设计中（百万级 DFF），缓冲复位树的综合和优化是后端实现的必要步骤。无缓冲线方案（直接导线）在小型设计或特定高速路径中使用，但扇出限制和延迟差异严重制约可扩展性。复位树的约束包括：恢复/移除时序满足、最大扇出和最大过渡时间（Max Transition）、以及极性一致（大多数标准单元 DFF 异步复位低电平有效，复位树末端需要保证正确极性）。

### 多时钟复位域规划

多时钟域 SoC 中，每个独立时钟域配置一个自己的复位同步器——从全局 POR 或系统复位信号在本地时钟域的"版本"。复位分区（Reset Domain Partition）确保每个域独立进行复位释放，且释放与各自时钟同步。复位排序（Reset Sequencing）定义多域之间的释放顺序——产生跨域信号的源域必须先于消费域解除复位，防止消费者采样到源域复位期间的不稳定输出。常见复位排序层级：PLL/OSC 域最先释放（提供稳定时钟源）→ 系统控制器域释放（管理全局状态）→ 高速域（CPU/GPU/NoC）→ 低速外设域。隔离单元（Isolation Cell）在源域处于复位时将输出强制到安全值（如全 0 或全 1），防止不定态传播。

### POR 电路

上电复位（Power-On Reset, POR）是芯片启动时产生初始复位脉冲的模拟电路。POR 内部监控电源电压 VDD——当 VDD 低于 POR 阈值时输出有效复位；当 VDD 超过阈值并在延迟后（滤除 VDD 上电震荡和环振）释放复位。传统 POR 的精度受限于模拟比较器的偏移和温度系数——数字辅助 POR 在先进工艺中通过 ADC 或数字计数器提高上电阈值精度。POR 输出通常经模拟滤波器（如 RC 滤波器消除高频噪声）后进入数字复位生成链：模拟 POR → 数字去毛刺滤波（脉冲扩展/同步消除）→ 每域复位同步器 → 各域复位分发树。某些系统额外集成欠压检测器（Brown-Out Detector, BOD），在 VDD 骤降至工作范围以下时再次触发复位。

### DFT 中的复位

可测试性设计对复位提出特殊约束。扫描模式需求：（1）复位必须可由测试设备（ATE）通过专用测试管脚独立控制；（2）扫描移位阶段需复位抑制——所有 DFF 的复位被强制关断以确保测试矢量在链上无干扰地串行移位；（3）扫描捕获阶段复位按 ATPG 预设的状态值控制——ATPG 能通过扫描链控制复位信号产生"异步复位→正常操作"和"正常运行→异步复位"的转换以覆盖复位路径的所有制造缺陷（Stuck-At、Transition）；（4）复位同步器在扫描模式下通常被旁路（复位同步器输出由 ATE 直接控制以加速测试，避免等待同步延迟）。某些设计使用测试模式复位网络（Test Reset Network），在测试模式中仅使用一个精简的中心化复位树以简化 ATPG 的复位控制。

### CDC 复位同步器

当复位信号从一个时钟域跨越到另一个域时，复位同步器起到 CDC 同步器的作用——确保复位释放按目标域时钟的安全边沿发生。如果两个域属于不同电压域且可选独立关断，需要隔离机制保证当源域已断电时目标域不会收到虚假的复位信号。隔离单元（Isolation Clamp）可在此情况下将跨域复位信号强制向上/下拉到有效安全值。

### 复位对不定态（X）传播的影响

复位设计直接影响仿真中不定态（X）的传播行为。异步复位的 DFF 在复位期间输出为 0（不复现 X），因此异步复位天然阻止 X 传播——这是基于仿真的门级验证（Gate-Level Simulation, GLS）与形式验证中异步复位优于同步复位的关键原因。同步复位在复位期间，如果时钟被门控而停止，DFF 输出保留不定态——如果下游组合逻辑使用该值则 X 大范围传播。在 UPF（Unified Power Format）的电源意图中，复位和隔离的协同定义是正确仿真关电域的关键——关电域的输出必须通过隔离单元驱动为 X-stable 值。

## 关键要点

- 同步复位的核心优势是时序可分析、毛刺免疫、DFT 友好，但致命缺陷是时钟未运行时完全失效
- 异步复位的优势是不依赖时钟即刻生效，但释放时恢复/移除违规导致亚稳态且对毛刺极度敏感
- 异步断言 + 同步解断言（复位同步器）是推荐模式——两段同步器第一级化解亚稳态、第二级提供干净复位
- 复位同步器与 2-FF CDC 同步器原理完全对映——都是两级 DFF 第一级吸收亚稳态、第二级输出干净信号
- 多时钟域复位分区：每域独立复位同步器；释放顺序：产生跨域信号的源域必须早于消费域释放
- POR 负责上电初始化，BOD 负责运行中电压跌落——两者经滤波后进入数字化同步级联
- DFT 要求测试模式中独立控制复位：扫描移位阶段抑制复位，捕获阶段按 ATPG 预设复位值
- 复位树的恢复/移除时序检查与数据路径的建立/保持检查共同构成 DFF 完整时序签名
- 异步复位天然阻止 X 传播——这是 GLS 仿真中异步复位优于同步复位的深层原因
