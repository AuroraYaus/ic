# 跨时钟域设计（Clock Domain Crossing, CDC）

跨时钟域设计（Clock Domain Crossing, CDC）处理数据在不同时钟域之间安全、可靠传输的问题。现代 SoC 包含数十至上百个时钟域——CPU、GPU、DDR 控制器、外设接口各自运行在不同频率和相位下——它们之间的数据交换必然穿越时钟边界。CDC 处理不当导致的亚稳态传播、数据一致性和功能故障在流片后呈现概率性、难以复现的失效模式，是数字IC设计中风险最高的隐患之一。

## 原理

### 亚稳态根源与 MTBF

CDC 的物理根源是亚稳态（Metastability）。触发器的双稳态交叉耦合反相器对在采样时刻如果数据处于建立/保持时间窗口内，输出电压可能落入亚稳态平衡点——既不完全是 0 也不完全是 1 的中间电平振荡。振荡在随机解析时间 $t_{res}$ 后衰减至稳定值。MTBF（Mean Time Between Failures）公式量化失败概率：

$$MTBF = \frac{e^{t_{res}/\tau}}{f_{clk} \cdot f_{data} \cdot T_0}$$

其中 $\tau$ 为解析时间常数（先进工艺约 50ps，7nm 典型值），$T_0$ 为采样窗口参数（约 $10^{-9}s$），$t_{res}$ 为允许的解析时间（目标时钟周期减去次级触发器建立时间）。MTBF 对 $t_{res}$ 极其敏感——增加半周期可将 MTBF 从数秒提升至数千年。

### CDC 场景分类与同步器

慢到快（Slow-to-Fast）：目标时钟远快于源时钟，数据在两次变化间被多次采样，2-FF 同步器处理亚稳态即可。快到慢（Fast-to-Slow）：源数据可能在目标域两次采样之间变化多次，除处理亚稳态外还需防止数据丢失——需脉冲展宽器或握手机制。

2-FF 同步器是单比特 CDC 标准方案：源域信号经目标域第一级 FF，其输出可能亚稳态；一个完整目标时钟周期后大概率（取决于 $t_{res}$ 和工艺 $\tau$）已稳定，再由第二级 FF 安全采样。MTBF 公式指导：对照 MTBF 目标（如 1000 年），可决定是否需要第三级 FF。

### 多比特 CDC 策略

对多比特信号使用独立 2-FF 同步器（每比特各一个）是严重错误——不同比特解析时间不同导致接收端可能采集到逻辑不一致的组合。

格雷码异步 FIFO（Gray-Coded Async FIFO）是多比特 CDC 的主力方案。核心：二进制码转格雷码 $g = b \oplus (b \gg 1)$，格雷码相邻值仅 1 bit 变化。写指针在写时钟域格雷编码后经 2-FF 同步到读域判断"空"（rptr_gray_sync == wptr_gray）；读指针在读域格雷编码后经 2-FF 同步到写域判断"满"（wptr_gray_sync 与 rptr_gray 的 MSB\:MSB-1 不同、其余位相同——超前一整圈）。格雷码的单比特变化确保同步后指针最多偏差一个位置——"空"和"满"判断偏保守但绝不溢出/下溢。

握手同步器（Handshake Synchronizer）：源域准备好数据后置 REQ，REQ 经 2-FF 同步到目标域，目标域采样数据后置 ACK，ACK 同步回源域释放。4 相握手（归零协议，REQ 上升$\to$ACK 上升$\to$REQ 下降$\to$ACK 下降）更简单健壮但每次传输 4 次同步穿越；2 相握手（非归零，REQ 翻转即请求）减少同步往返次数、吞吐率更高。

DMUX 同步器（Data MUX with Toggle）：单条控制比特经 2-FF 同步到目标域选通数据总线，数据总线保证在控制信号稳定期间不变——巧妙的面积优化方案，但仅适用于数据变化率远低于目标时钟的场景。

### CDC 故障模式与验证

同步器失效不仅限于亚稳态传播：数据一致性丢失（多比特 CDC 无保护）、毛刺传播（组合逻辑输出直接跨域而不经触发器）、再收敛发散（Reconvergence Divergence——多路信号分别经不同同步器后到达的组合逻辑节点，各路径延迟差异导致错误的中间组合状态）。

CDC 验证方法论：结构检查（同步器存在性——每条跨域路径必须有同步器）；协议检查（握手完整性、格雷码编码正确性、FIFO 满/空逻辑一致性）；再收敛分析（多同步器输出汇聚点的时序安全）。工具（SpyGlass CDC、Questa CDC、JasperGold CDC）在 RTL 层做静态分析——仿真无法发现 CDC 问题，亚稳态是概率性、工艺特定、频率敏感的现象。

### CDC 约束与时序例外

CDC 路径在 STA 中需专门的时序例外（Timing Exception）处理。异步时钟域之间没有确定相位关系，工具无法进行有意义的建立/保持时间检查——若放任 STA 分析每条跨域路径会产生大量虚假违例。典型 CDC 约束：时钟分组（`set_clock_groups -asynchronous`）声明互异步时钟组；跨域假路径声明（`set_false_path`）对已由同步器保护的数据路径设假路径；最大延迟约束（`set_max_delay`）对同步器链第一级到第二级间设合理延迟上限确保物理安全。SpyGlass CDC 自动识别同步器结构并交叉检查 STA 约束——标记有同步器无对应假路径（Missing False Path）以及有假路径无对应同步器（Over-constrained）的失配。

### CDC 同步器的重收敛风险

常被忽视但致命的 CDC 问题是同步器的重收敛（Reconvergence）。来自同一源域的多条信号各自经独立同步器进入目标域后，在目标域组合逻辑中重新合并时——各同步器输出可能在不同目标周期稳定，若组合逻辑依赖"同时到达"，产生功能错误。典型重收敛风险：（1）同一总线经各自 2-FF 同步器的多条控制信号在目标域合并——组合输出可能单周期内多次翻转；（2）"数据有效"指示信号经独立同步器而数据总线经 FIFO/握手——指示信号的同步延迟可能早于或晚于数据实际稳定时刻。最佳实践：对所有需要在目标域合并的信号，汇集到一个 CDC 结构（DMUX 或多比特握手）中传输，或确保接收端组合逻辑不依赖"同时到达"假设。

### 异步 FIFO 的深度选择与溢出保护

异步 FIFO 的深度选择需要同时考虑跨域吞吐率匹配和同步延迟。最小 FIFO 深度取决于最差情况下的写入速率与读取速率差异以及同步器的往返延迟（写指针同步到读域、读指针同步回写域各需 2-3 个目标时钟周期）。FIFO 深度不足导致溢出（Overflow）时数据丢失、不足导致下溢（Underflow）时读出无效数据——两者都是功能性故障。现代设计常用 Credit-Based 流控与异步 FIFO 配合：接收端周期性地向发送端报告可用空间（Credit），发送端在 Credit 耗尽前停止发送——避免 FIFO 溢出。格雷码 FIFO 的"几乎满"（Almost Full）和"几乎空"（Almost Empty）阈值可编程标志在满/空前提供预警，允许上层协议提前响应。

### 格雷码二进制双向转换

格雷码编码的关键是二进制与格雷码之间的双向转换电路。二进制转格雷码（Binary-to-Gray）：g[n-1] = b[n-1]（MSB 保留），g[i] = b[i+1] XOR b[i]（i 从 0 到 n-2），仅需一级 XOR 逻辑——组合路径极短，可在单个时钟周期内完成。格雷码转二进制（Gray-to-Binary）：b[n-1] = g[n-1]，b[i] = b[i+1] XOR g[i]（i 从 n-2 到 0），需要级联 XOR 链——组合路径深度为 n-1 级，对于宽指针（如 12-16 位）可能成为关键时序路径，需评估是否影响目标频率。实际设计中二进制转格雷在写/读域本地完成（各域各自的时钟），格雷码本身直接跨域（经 2-FF 同步），最终在目标域与域内二进制指针比较前视需求决定是否转回二进制——通常空/满比较可直接在格雷码域完成，避免转回二进制的级联 XOR 延迟。

### 脉冲同步器与边沿检测

对于源域产生的脉冲信号（单周期宽度的信号），简单的 2-FF 同步器可能完全漏掉——目标时钟周期长于源时钟周期时，脉冲在目标域两次采样之间产生和消失。脉冲同步器（Pulse Synchronizer）解决了这个问题：在源域将脉冲转换为电平翻转（Toggle FF——每个脉冲翻转一次输出），电平信号经 2-FF 同步到目标域，然后在目标域通过边沿检测器（Rising Edge Detector——当前值 XOR 前一周期值）恢复为脉冲。这个方案保证所有脉冲都被捕获（因为电平不会"丢失"），但引入了最小脉冲间隔限制——两个连续脉冲之间必须有足够的间隔使翻转电平能传播到目标域并被检测到。在设计接口协议时需确保源域的脉冲产生速率满足这一约束——通常是目标时钟周期的 2-3 倍。

## 关键要点

- 亚稳态根本原因是双稳态元件的物理特性：$\tau \approx 50ps$（7nm），MTBF 对允许的解析时间有指数级敏感性
- 2-FF 同步器是单比特 CDC 标准方案：第一级承担亚稳态风险，第二级安全采样；极高频下需三级同步
- 快到慢 CDC 额外需防数据丢失——异步 FIFO 或握手机制，不能仅靠 2-FF 同步器
- 格雷码 FIFO 是多比特 CDC 主力：指针格雷编码确保同步后最多偏差一个位置，"空"/"满"保守但安全
- 对多比特信号使用独立 2-FF 同步器是严重设计错误——各比特解析时间不同导致数据一致性破坏
- 4 相握手简单健壮，2 相握手吞吐更高但控制逻辑复杂；均适合低频控制信号 CDC
- 再收敛发散（多路同步信号重新组合）是常被忽视的 CDC 故障模式——需验证工具专门检测
- CDC 验证工具是唯一可靠保证——仿真无法重现亚稳态的概率性行为

### 格雷码编码与双向转换

格雷码编码的核心是二进制与格雷码之间的双向转换。二进制转格雷码（Binary-to-Gray）：最高位保留，g[i] = b[i+1] XOR b[i]（i 从 0 到 n-2），仅需一级 XOR 逻辑——组合路径极短，可单周期完成。格雷码转二进制（Gray-to-Binary）：b[n-1] = g[n-1]，b[i] = b[i+1] XOR g[i]（i 从 n-2 到 0），需级联 XOR 链——组合路径深度为 n-1 级，对于 12-16 位宽指针可能成为关键时序路径。实际设计中二进制转格雷在写/读域本地完成（各域各自的时钟），格雷码本身经 2-FF 同步直接跨域，空/满比较通常可直接在格雷码域完成，避免转回二进制的级联 XOR 延迟。

### 脉冲同步器与边沿检测

对于源域产生的单周期脉冲信号，简单 2-FF 同步器可能完全漏掉——目标时钟周期长于源时钟周期时脉冲在两次采样之间产生和消失。脉冲同步器（Pulse Synchronizer）解决此问题：在源域将脉冲转换为电平翻转（Toggle FF——每个脉冲翻转输出），电平信号经 2-FF 同步到目标域，然后在目标域通过边沿检测器（Rising Edge Detector，当前值 XOR 前一周期值）恢复为脉冲。此方案保证所有脉冲都被捕获（电平不会丢失），但引入最小脉冲间隔限制——两个连续脉冲间必须有足够间隔使翻转电平传播到目标域并被检测到，通常为目标时钟周期 2-3 倍。设计接口协议时需确保源域脉冲产生速率满足此约束。
