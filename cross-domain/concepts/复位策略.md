# 复位策略

复位（Reset）是数字系统中将电路强制置入已知初始状态的机制。复位设计看似简单，但在大规模 SoC 中涉及同步-异步选择、复位树的时序收敛、多时钟域复位排序、DFT 兼容性和功耗控制等多个维度——不当的复位设计是芯片死机（Deadlock）、不定态传播（X-propagation）、和硅后调试困难的常见根源。

## 原理

### 同步复位

同步复位（Synchronous Reset）在每个 DFF 的数据输入端通过 AND 门或 MUX 与复位信号组合，复位仅在时钟边沿生效。SystemVerilog 编码模式：`always_ff @(posedge clk) if (!rst_n) q <= 1'b0; else q <= d;`。优点：100% 同步时序——不引入任何异步路径，STA 可完全分析复位到输出的延迟，复位信号无需特殊处理即可被时钟自然屏蔽毛刺（Glitch），DFT 扫描模式下复位完全由时钟控制。缺点：（1）时钟未运行时复位完全无效——这是同步复位的致命缺陷，因为上电阶段时钟振荡器尚未稳定启动，同步复位无法在这期间产生作用；（2）复位逻辑纳入数据路径增加 DFF 数据输入端的扇入（Fan-In），可能成为关键时序路径的瓶颈；（3）需要额外的时钟门控单元确保即使在复位期间时钟持续运转，否则 DFF 可能漏采复位事件。

### 异步复位

异步复位（Asynchronous Reset）直接连接到 DFF 的异步复位/置位引脚（`always_ff @(posedge clk or negedge rst_n)`），复位不依赖时钟沿，电平敏感、立即生效。优点：时钟未运行时也生效——这是 POR 阶段的关键需求；不复用数据路径因此不增加 DFF 数据输入端负载；DFF 复位输入本身就是异步的，不引入组合逻辑延迟。缺点：（1）复位释放（Reset Release / Deassertion）——如果异步复位撤销信号的边沿与时钟沿距离过近，违反恢复时间（Recovery Time, Trem）或移除时间（Removal Time, Tremov），DFF 将进入亚稳态；（2）异步复位对毛刺极度敏感——复位输入上的即便是一个短暂的噪声脉冲也会触发全系统复位；（3）异步复位路径不在 STA 的常规时序分析内，需要专门的恢复/移除时序检查（`.lib` 中的 `recovery` 和 `removal` 时序弧）。

### 异步断言 + 同步解断言模式

业界标准的复位方案是异步断言 + 同步解断言（Asynchronous Assert, Synchronous Deassert），结合了两者的优势：上电和异常时异步即时进入复位状态，但复位释放被时钟边沿同步化以消除恢复/移除时序违规。实现的电路为复位同步器（Reset Synchronizer）：外部异步复位信号（POR 输出或外部管脚）异步置位两级串联的 DFF，DFF 输入端固定接高电平（1'b1）；当外部复位信号释放时，第一级 DFF 在紧接的时钟沿采样高电平解除复位，经过一个时钟周期的解析时间后第二级 DFF 跟随解除。两级 DFF 的输出即"同步化"的复位信号——确保释放边沿相对于目标时钟满足 Removals/Recovery 时序要求。

复位同步器与 2-FF CDC 同步器原理完全对偶——第一级 DFF 承担亚稳态风险（复位释放与时钟沿可能位于恢复/移除窗口内），第二级 DFF 输出干净的已同步复位信号。关键设计要点：同步器的两级 DFF 之间无组合逻辑（保持最大解析时间预算），且 DFF 必须使用带异步复位/置位引脚的单元（异步复位端接外部复位，数据端接 VDD）。

### 复位树与分布

复位信号需要分发到芯片上成千上万个 DFF，形成复位树（Reset Tree）。缓冲复位树采用类似时钟树综合（CTS）的策略——插入多级缓冲器平衡至多个加载端的延迟，使所有 DFF 在同一时钟沿附近解除复位，避免不同 DFF 解除复位的时间差异导致不定态交互。在大规模设计中（百万级 DFF），缓冲复位树的综合和优化是后端实现的必要步骤。无缓冲线方案（直接导线）在小型设计或特定高速路径中使用，但扇出限制和延迟差异严重制约可扩展性。复位树的约束包括：恢复/移除时序满足、最大扇出和最大过渡时间（Max Transition）、以及极性一致（大多数标准单元 DFF 异步复位低电平有效，复位树末端需要保证正确极性）。在实际物理实现中，复位树综合（RTS）生成的缓冲器级数通常在 5-10 级（取决于芯片面积和 DFF 数量），复位树的端到端延迟需控制在 1-3 个时钟周期以内以保证释放的一致性。复位树的最后一级缓冲器应尽量靠近目标 DFF 放置，减少长走线引入的 IR-drop 耦合噪声——长走线上耦合噪声产生的电压波动可能被 DFF 误识别为复位脉冲。

### 多时钟复位域规划

多时钟域 SoC 中，每个独立时钟域配置一个自己的复位同步器——从全局 POR 或系统复位信号在本地时钟域的"版本"。复位分区（Reset Domain Partition）确保每个域独立进行复位释放，且释放与各自时钟同步。复位排序（Reset Sequencing）定义多域之间的释放顺序——产生跨域信号的源域必须先于消费域解除复位，防止消费者采样到源域复位期间的不稳定输出。常见复位排序层级：PLL/OSC 域最先释放（提供稳定时钟源）→ 系统控制器域释放（管理全局状态）→ 高速域（CPU/GPU/NoC）→ 低速外设域。隔离单元（Isolation Cell）在源域处于复位时将输出强制到安全值（如全 0 或全 1），防止不定态传播。

### POR 电路

上电复位（Power-On Reset, POR）是芯片启动时产生初始复位脉冲的模拟电路。POR 内部监控电源电压 VDD——当 VDD 低于 POR 阈值时输出有效复位；当 VDD 超过阈值并在延迟后（滤除 VDD 上电震荡和环振）释放复位。传统 POR 的精度受限于模拟比较器的偏移和温度系数——数字辅助 POR 在先进工艺中通过 ADC 或数字计数器提高上电阈值精度。POR 输出通常经模拟滤波器（如 RC 滤波器消除高频噪声）后进入数字复位生成链：模拟 POR → 数字去毛刺滤波（脉冲扩展/同步消除）→ 每域复位同步器 → 各域复位分发树。某些系统额外集成欠压检测器（Brown-Out Detector, BOD），在 VDD 骤降至工作范围以下时再次触发复位。

### DFT 中的复位

可测试性设计对复位提出特殊约束。扫描模式需求：（1）复位必须可由测试设备（ATE）通过专用测试管脚独立控制；（2）扫描移位阶段需复位抑制——所有 DFF 的复位被强制关断以确保测试矢量在链上无干扰地串行移位；（3）扫描捕获阶段复位按 ATPG 预设的状态值控制——ATPG 能通过扫描链控制复位信号产生"异步复位→正常操作"和"正常运行→异步复位"的转换以覆盖复位路径的所有制造缺陷（Stuck-At、Transition）；（4）复位同步器在扫描模式下通常被旁路（复位同步器输出由 ATE 直接控制以加速测试，避免等待同步延迟）。某些设计使用测试模式复位网络（Test Reset Network），在测试模式中仅使用一个精简的中心化复位树以简化 ATPG 的复位控制。

### CDC 复位同步器

当复位信号从一个时钟域跨越到另一个域时，复位同步器起到 CDC 同步器的作用——确保复位释放按目标域时钟的安全边沿发生。如果两个域属于不同电压域且可选独立关断，需要隔离机制保证当源域已断电时目标域不会收到虚假的复位信号。隔离单元（Isolation Clamp）可在此情况下将跨域复位信号强制向上/下拉到有效安全值。

### 复位对不定态（X）传播的影响

复位设计直接影响仿真中不定态（X）的传播行为。异步复位的 DFF 在复位期间输出为 0（不复现 X），因此异步复位天然阻止 X 传播——这是基于仿真的门级验证（Gate-Level Simulation, GLS）与形式验证中异步复位优于同步复位的关键原因。同步复位在复位期间，如果时钟被门控而停止，DFF 输出保留不定态——如果下游组合逻辑使用该值则 X 大范围传播。在 UPF（Unified Power Format）的电源意图中，复位和隔离的协同定义是正确仿真关电域的关键——关电域的输出必须通过隔离单元驱动为 X-stable 值。

### 复位毛刺滤除（Glitch Filtering）

异步复位路径对毛刺极度敏感——电源噪声、电磁干扰（EMI）、相邻高速信号串扰（Crosstalk）甚至静电放电（ESD）事件都可能使复位信号出现亚纳秒级的杂散脉冲，若不加滤除即触发全芯片复位。复位毛刺滤除通常由一个输入去毛刺单元（Deglitch Cell）实现——复位信号经过 RC 低通滤波器消除高频噪声，再进入施密特触发器（Schmitt Trigger）将缓变边沿还原为陡峭的数字边沿。整个滤除链的延迟（典型的 RC 时间常数加施密特迟滞时间）决定了最小可检测的有效复位脉冲宽度——通常在数百纳秒量级（如 200-500ns）。滤除器在 POR 电路和外部复位管脚（如 NRST）之后优先放置，位于复位同步器链条的上游，确保噪声不被传播到内部复位网络。

现代工艺节点（7nm 及以下）中，电源噪声的频率和幅度增加使毛刺滤除的设计裕度面临更大挑战——需要在滤除能力（更大的 RC 常数）和响应速度（更短的毛刺滤除延迟）之间权衡。某些设计使用数字毛刺滤除器（Glitch-Free Reset Generator），通过计数器对复位信号进行采样：仅在复位电平稳定维持 N 个连续时钟周期后才认定为有效复位事件，兼顾了滤除效果和可配置性。模拟去毛刺单元的 RC 滤波器截止频率通常设置在几十 MHz 量级（如 10-30MHz），确保高频 EMI/Crosstalk 噪声被大幅衰减而又不过度减慢有效复位信号的边沿转换速度（Slew Rate）——过慢的边沿会导致施密特触发器输出抖动。数字去毛刺的采样窗口 N 通常配置为 3-5 个时钟周期，在保证滤除效果的同时将对复位响应延迟的影响控制在微秒以内。

### 时钟门控与复位的协同

时钟门控（Clock Gating）与复位的交互是 SoC 设计中复杂的设计约束。当复位信号处于有效状态时，如果时钟被门控（停止），同步复位的 DFF 将无法采样复位——这是同步复位最严重的故障模式。即使使用异步复位，在复位释放阶段如果时钟尚未启动（如 PLL 锁定前），释放边沿无时钟沿相伴，可能导致复位同步器无法正确解析复位释放事件。为解决此问题，设计必须保证复位同步器的时钟在复位释放前已稳定运行——通过复位排序将时钟源的释放置于复位同步器释放之前：先释放 PLL/OSC 时钟 → 等待时钟稳定（通常需数百微秒）→ 再释放复位同步器 → 最后释放各域功能复位。在 UPF 定义的电源域中，时钟门控使能信号需与对应域的隔离控制信号协同，避免在域上电/掉电过程中的瞬时时钟脉冲产生虚假复位事件。此外，对于使用动态电压频率调节（DVFS）的系统，在频率切换过程中必须冻结复位释放逻辑——过渡时钟沿可能出现在任意时刻，其不确定性会在复位释放阶段引入无法预判的恢复/移除时序违规。

在实际 SoC 设计中，还应注意复位信号在芯片封装管脚级的处理。外部 NRST 管脚通常配备可选的内部上拉电阻（Weak Pull-Up, 典型值 50-100kΩ）和外部的下拉电容（典型值 100nF），形成硬件级低通滤波器，在进入芯片 I/O 焊盘（Pad）后由施密特触发器输入缓冲器（Schmitt Trigger Input Buffer）进行波形整形。该外部 RC 网络与芯片内部的数字去毛刺电路串联形成级联滤波——外部滤除微秒级噪声，内部滤除纳秒级杂散脉冲，共同保证复位信号的完整性。

## 关键要点

- **同步复位的优势与致命缺陷**：时序可分析、毛刺免疫、DFT 友好，但时钟未运行时完全失效
- **异步复位的优势与风险**：不依赖时钟即刻生效，但释放时恢复/移除违规导致亚稳态且对毛刺极度敏感
- **异步断言 + 同步解断言是推荐复位模式**：两段同步器第一级化解亚稳态、第二级提供干净复位
- **复位同步器与 CDC 同步器原理对偶**：都是两级 DFF 第一级吸收亚稳态、第二级输出干净信号
- **多时钟域复位分区与释放顺序**：每域独立复位同步器；产生跨域信号的源域必须早于消费域释放
- **POR 与 BOD 的分工与协作**：POR 负责上电初始化，BOD 负责运行中电压跌落，两者经滤波后进入数字化同步级联
- **DFT 对复位控制的特殊要求**：扫描移位阶段抑制复位，捕获阶段按 ATPG 预设复位值
- **恢复/移除与建立/保持同等重要**：两者共同构成 DFF 完整时序签名
- **异步复位天然阻止 X 传播**：这是 GLS 仿真中异步复位优于同步复位的深层原因
- **外部复位管脚必须经毛刺滤除链**：NRST 首先经过施密特触发器和 RC 低通滤波，再接入内部复位同步器，缺失该链路的芯片极易受干扰而异常复位
- **恢复/移除是 STA Signoff 必要检查项**：与建立/保持检查地位同等，`.lib` 中的 recovery/removal 时序弧定义了 DFF 的复位释放窗口
- **DFT 中复位同步器 D 端需扫描可控**：确保 ATPG 能直接强制复位状态而不依赖外部复位管脚的上电序列
- **时钟门控与复位交互是同步复位的致命弱点**：复位期间时钟停止导致同步复位 DFF 完全失效；异步复位虽不受此限但释放前仍需时钟已稳定
- **POR 释放前不依赖寄存器初始值**：上电后复位信号被 POR 驱动到有效状态，设计应确保在 POR 释放前不依赖任何寄存器的初始值（因未释复位的寄存器值不定）
- **DVFS 频率切换时必须冻结复位释放**：过渡时钟沿的不确定性会在异步复位释放阶段引入无法预判的恢复/移除违规
- **ASIC 与 FPGA 的复位策略不可直接移植**：FPGA 通常使用同步复位（异步复位资源有限），但 ASIC 的时钟启动延迟和 POR 序列在 FPGA 中不适用
- **复位树是仅次于时钟树的第二大高扇出网络**：扇出达数十万级别，其综合质量直接影响芯片的复位释放一致性
- **复位状态机管理复杂复位序列**：硬件 FSM 替代简单的计数器链，支持各域的独立复位请求、看门狗触发、软件复位等复杂复位源调度
- **系统级复位需考虑 ESD 保护**：若不加 ESD 二极管钳位，静电放电可能击穿复位接收电路导致永久损伤

## 与其他概念的关系

- [[cross-domain/concepts/跨时钟域设计|跨时钟域（CDC）]] — 复位同步器与信号 CDC 同步器原理对偶（两级 DFF 吸收亚稳态）；复位域跨越是 CDC 的特殊子问题，复位释放时序与 CDC 信号同步共享相同的 MTBF 分析框架
- [[concepts/亚稳态|亚稳态（Metastability）]] — 异步复位释放时恢复/移除时序违规导致亚稳态——复位同步器通过同一原理解决；CDC 同步器和复位同步器的第一级 DFF 都承担亚稳态风险，第二级输出干净信号
- [[asic-flow/concepts/可测试性设计|可测试性设计（DFT）]] — DFT 模式对复位信号的独立控制和同步器旁路是扫描测试的关键需求；ATPG 需能通过扫描链控制复位信号以覆盖异步复位/置位引脚的 Stuck-At 和 Transition 故障
- [[cross-domain/concepts/低功耗设计|低功耗设计（Low-Power Design）]] — UPF 电源意图中复位与隔离协同定义关电域行为；POR 序列与多电压域的驱动顺序深度耦合；电源域的关断和上电需与对应域的复位状态机严格协同
- [[asic-flow/concepts/静态时序分析|静态时序分析（STA）]] — 复位路径的恢复/移除时序检查是 STA Signoff 的必要部分，与数据路径的建立/保持检查共同构成 DFF 的完整时序签名
- [[asic-flow/concepts/时钟树综合|时钟树综合（CTS）]] — 复位树综合（Reset Tree Synthesis, RTS）借鉴 CTS 的缓冲器插入和延迟平衡技术，确保多 DFF 在同一个时钟边沿解除复位
